Pb₂Bi₂Te₅ 的 n 型倾向从哪里来：长键、反位缺陷与阳离子空位

报告补充章节 · 2026-11-25 · 只使用仓库中已有的缺陷形成能、COGITO 成键、ES/ET 与带边投影数据，未运行新的 DFT。生成脚本 10_脚本/pbbi_ntype_mechanism.py，源数据见本目录 源数据/。
待检验的命题：“PbBiTe 是 n 型的原因与 Pb 和 Bi 元素有关：它们更容易形成长键的共价键，可以去形成反位缺陷。”
结论速览
  • 与 Pb、Bi 有关——成立，但需要两者的组合。四种 A₂B₂Te₅ 共 18 个化学势顶点中，只有 Pb₂Bi₂Te₅ 的 v3 出现 n 型；把 Bi 换成 Sb 或把 Pb 换成 Sn，n 型都消失（图 1）。
  • “长键”——主要是 Bi 位的性质，而且更接近 metavalent 键而不是经典共价键。Pb–Te 两组键几乎等长（3.21/3.22 Å）；长键在 Bi–Te（3.25 Å），其 ES ≈ 0.76，低于 1（图 2）。
  • “长键使反位容易”——是 Bi 的作用，不是 Pb 的作用。阳离子交换能随 A、B 两个位点的尺寸差单调变化；Sb→Bi 降低交换能，Sn→Pb 反而升高（图 3）。最容易互换的是 Sn₂Bi₂Te₅（0.22 eV），但它是 p 型，说明“反位容易”只决定补偿强弱，不决定导电符号。
  • 命题中缺失的一环：Pb 空位受主难以形成。在最有利 n 型的条件下把 E_F 放到 CBM，两种 Pb 化合物的 v_Pb 仍为 +0.473 / +0.543 eV，两种 Sn 化合物的 v_Sn 已降到 −0.107 / −0.110 eV，正是 v_Sn 把 Sn₂Bi₂Te₅ 钉回 p 型（图 5、6）。这与 Pb 6s² 惰性的图像一致（Pb₂Bi₂Te₅ 的 VBM 中 Pb-s 仅 3.0%，Sn₂Bi₂Te₅ 中 Sn-s 为 24.8%），但 VBM 组成并不能单独解释四种材料的差别（图 4）。
  • 可靠性：唯一的 n 型点施主与受主几乎简并、强烈补偿，结果对计算误差非常敏感；见第 7 节。

1　先确认现象：哪些材料、哪些条件给出 n 型

原模型（缺陷数据包中的电荷平衡输出）在多数顶点出现负形成能与浓度饱和，直接比较载流子浓度并不稳健。为此本节使用一个只依赖现有形成能、物理意义更直接的判据：在每个化学势顶点下，求最低能带正电缺陷与最低能带负电缺陷形成能相等时的费米能级 E_F*，即本征缺陷对费米能级的钉扎位置。E_F* 高于带隙中点记为 n 倾向，否则记为 p 倾向。用这一判据得到的类型与原模型在 18/18 个顶点上一致。作为数据复核，由各数据包 v0 记录重建的形成能与源记录中每个顶点的最低缺陷全部吻合（最大偏差 0 eV，即在源数据的有效位数内一致）。

对原命题的修正：Pb 自身并不形成“更长的键”。Pb–Te 两组键几乎等长（3.21/3.22 Å，ICOHP 比 0.89），Pb 处在近乎规则的八面体中，这正是 6s² 孤对不表现立体化学活性的结构特征。长短键分化来自 B 位：Bi 的长键（ES ≈ 0.76）比 Sb 的长键更长、共享电子更少。因此建议论文中把“长键的共价键”写成“Bi 位的 metavalent 长键”。

3　“从而容易形成反位”：交换难易由 A、B 位点的相似度决定

反位缺陷的形成能含有化学势项，跨材料直接比较没有意义。但把一对互补反位相加时，化学势项正好抵消：交换能 E(B_A⁰) + E(A_B⁰) 表示把一个 A 和一个 B 互换位置的本征代价，可以在四种材料之间直接比较。

表 3 给出两点补充。第一，Bi 系中 A、B 的 Bader 电荷几乎相同（Pb₂Bi₂Te₅：Pb +0.66、Bi +0.69），化学环境的相似也支持“容易互换”；但电荷差的排序与交换能并不完全一致，几何尺寸是更好的描述量。第二，四种材料的 B_A 施主 (0/+1) 能级都高于各自带隙，都是浅施主，所以“施主是否浅”不能区分 n 型和 p 型。

关键推论：交换能最低的是 Sn₂Bi₂Te₅（0.224 eV），而它在所有顶点都是 p 型。可见反位容易只意味着施主、受主反位都多、补偿强，并不决定净载流子的符号。原命题从“容易反位”直接推到“n 型”，中间缺了一步。

小结：阳离子空位的形成能按 A 元素分成两组。在 E_F = CBM 时，v_Pb 在两种 Pb 化合物中都为正（+0.473、+0.543 eV），v_Sn 在两种 Sn 化合物中都为负（−0.107、−0.110 eV）。所以 Pb 的作用是关掉阳离子空位这条受主通道。但 Pb 只是必要条件：Pb₂Sb₂Te₅ 同样没有空位受主，却因为 Pb_Sb 受主反位低于 Sb_Pb 施主而保持 p 型，还需要 Bi 让施主反位足够有利。这正是“Pb＋Bi 组合”的含义。

6　建议的论文表述

Pb₂Bi₂Te₅ 的 n 型倾向源于 Pb 与 Bi 的组合效应。Bi 形成长的 Bi–Te metavalent 键（3.25 Å，ES ≈ 0.76），使 Bi 位八面体在尺寸和电荷上接近 Pb 位（平均键长差 0.050 Å，Bader 电荷 +0.66/+0.69），阳离子交换能降至 0.39 eV，因此 Bi_Pb 与 Pb_Bi 反位大量共存并相互补偿；在贫 Pb、富 Te 条件下，浅施主 Bi_Pb 与受主 Pb_Bi 能量相当。与此同时，Pb 空位受主难以形成（E_F = CBM 时仍为 +0.473 eV），这与 Pb 6s² 的惰性一致（VBM 中 Pb-s 仅约 3%），费米能级因而可以接近并越过导带底。在 Sn₂Bi₂Te₅ 中，Sn 空位受主占据这一位置，材料保持 p 型。

如果需要保留原句的结构，最小修改是：“……与 Pb 和 Bi 元素的组合有关：Bi 的长键使 Bi、Pb 两个位点相近，容易形成反位缺陷；而 Pb 的惰性 6s² 抑制了阳离子空位，使施主反位 Bi_Pb 得以主导。”

把机制坐实所需的计算

  1. 在一致的超胞中充分弛豫 Bi_Pb⁺、Pb_Bi⁻、v_Pb²⁻ 与 Sn 系对应缺陷，并做有限尺寸修正；检验 v3 的施主优势是否超过误差尺度。
  2. 用 HSE 或带隙修正后的带边重新求电荷中性解，确认 E_F* 与 CBM 的相对位置。
  3. 对 Bi_Pb 与 Bi_Sn 的局部环境做 COHP/差分电荷分析，直接检验“长键使 Bi 适应 A 位”。
  4. 比较 v_Pb 与 v_Sn 形成前后的价带顶 s–p 反键权重，闭合“6s² 惰性 → 空位难形成”这一环。
