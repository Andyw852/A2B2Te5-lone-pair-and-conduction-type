# 两个问题：思路、计算步骤与进度（总入口）

2026-10-22 更新。**新发现的最大问题**：HSE 与 PBE 在 Γ 附近的能带形状不同，刚性剪刀不成立（12_ 第 3.2 节），所以新增计算 1-0，排在所有能带相关计算之前。另外重新评估了还要补哪些计算（第 3 节状态列、第 5 节）；B 位偏心模式的 ODP 已用 λ 扫描估算，不再单独算。所有后续计算以本页为准；集群资源、作业号和踩过的坑见 [`运行记录.md`](运行记录.md)。

- **问题一**：只用理论计算说明孤对电子与 S 及其他 ZT 参数的关系，p 型和 n 型分开。
- **问题二**：退火前（晶格无序）和退火后（有序）的主导缺陷，以及 p/n 转变。

## 1 思路

**问题一的结论链**：孤对电子（成键）→ 改变了哪些能带特征 → 影响了哪些输运量。

| 层次 | 看什么 | 用什么判断 |
|---|---|---|
| 成键 | 阳离子 s 与 Te-p 的反键强度、s 能级位置、B 位偏心 | 带边 s 投影；COHP；E(λ) |
| 能带 | 带隙与 Γ 点带序、谷结构、单谷质量 | 密网格能带；λ=0 对照；无 SOC 对照 |
| 输运 | S（同浓度、低浓度）、μ、κₑ | BoltzTraP2、AMSET |
| 机制 | 电声耦合 | POP（已算）；A1g 模的光学形变势（ODP） |

**因果证据**来自“把畸变关掉”的反事实计算（15_ 的 λ=0）。在此之前，材料之间的对比只能算相关性。

**问题二的结论链**：有序化（D → V → O）→ 主导缺陷的种类和施主/受主属性 → 导电类型。第二层：用带电态求出平衡费米能级和净载流子浓度，再代入问题一的 S(n) 曲线，得到理论预测的退火前后 S。

**两个问题的衔接**：同浓度下 p 型 S 与材料无关，所以 S 的差别主要来自载流子浓度，也就是缺陷。另一方面，S 的正负不等于净载流子类型：300 K 时，净电子浓度要超过 1.1e18（PbBi）到 3.0e18（PbSb）才能测到负的 S（12_ 第 3 节）。

## 2 目前的结论（p 型和 n 型分开）

| | p 型（价带） | n 型（导带） |
|---|---|---|
| 带边 s 成分 | A、B 两个位置都是 6s 比 5s 少：Pb-s 7.6–9.5% 对 Sn-s 16.7–17.9%，Bi-s 4.7–4.8% 对 Sb-s 7.7–9.0% | 四种材料相近（总 s 12.6–14.9%，A-s 2–4%） |
| 谷结构 | 随 B 位变化：Sb 系一组 12 重谷离价带顶 5–20 meV，Bi 系 20–30 meV | 随 A 位变化：Pb 系是 Γ–A 轴上 2 个谷；Sn 系导带底偏离轴，很可能是环状极小 |
| 同浓度 S（≥3e19） | 四种材料相同，m\*_S 0.93–0.99 mₑ | Sn 系高 25–45%，来自导带底态密度大；1e20 时差别消失 |
| 低浓度 S | 有上限：PbSb 231，其余 303–324 µV/K，峰值在 3e18–1e19，高低随带隙变化 | 本征状态 S 为正（+86 到 +191），净电子浓度低于 1–3e18 时 S 仍为正 |
| 迁移率（密网格，300 K，四个材料） | A 位 Pb→Sn：Sb 系 ×1.6、Bi 系 ×1.13；B 位 Sb→Bi：Pb 系 ×1.21、Sn 系 ×0.84。差别主要来自 POP 耦合（Bi 使 ε∞ 增大）和电导质量；1e19 时 Sn 系比这两个量的预测高 25–40%，原因未定 | A 位 Pb→Sn ×0.47–0.65，B 位 Sb→Bi ×0.70–0.97；由电导质量（Sn 系重）和 POP 耦合完全解释（误差约 10%） |
| Lorenz 数 @1e19 | 只有 PbSb 明显偏高（5.3）；双极项占 κₑ：PbSb 70%，其余 25–29% | 四种都偏高（3.3–6.7）；双极项占 κₑ 37–75% |
| 扣除双极项后的 Lorenz 数 @1e19 | 1.56–1.80 | 1.52–2.11 |
| 主导散射 | POP | POP |

- **前提有问题**：下面所有涉及能带形状的结论（谷结构、m\*、同浓度 S、低浓度 S、电导质量和迁移率、λ 扫描的谷数变化）都建立在 PBE+SOC 的带边形状上。而 HSE 把四种材料的带边都移到了 Γ 附近，HSE 对带隙的修正在 Γ 点为 −116 到 −244 meV，在其他 k 点为正，两者最多相差 360–830 meV（12_ 第 3.2 节）。这些结论要等 1-0 用 HSE 级别的能带重做后才能确定。不依赖能带形状的结论有：POP 占主导、Lorenz 数偏高来自双极（机理层面）、回中能量、缺陷化学。
- **已确定（PBE+SOC 能带下）**：带边 s 占比不直接决定同浓度下的 S，且这一点不随带隙变化（12_ 第 3.1 节）。Lorenz 数偏高完全来自双极热导，单载流子部分只有 1.5–2.1（18_ 第 3.1 节）。POP 散射占主导，它来自 p 电子的共振成键（大的 Z\* 和 ε∞），s² 惰性是共振成键的前提；四种材料都一样。旧的 12×12×2 迁移率低估了 3–4 倍，已作废。
- **有证据、待验证**：低浓度、高温下的 S 与 κₑ 几乎只由带隙决定（带隙敏感性已证实：S 最大值、n 型变号阈值、双极项都随带隙单调变化，四种材料落在同一条线上）。还没确定的是：① 带隙的差别是否来自孤对电子（15_）；② 带隙本身是否可靠（1-8）。PbSb 的 HSE 路径带隙 0.065 eV 是四种中最小的，而 PBE 带隙 0.219 eV 却是最大的。
- **还没有结论**：
  - “6s 惰性”和“6p 的自旋轨道耦合”在这个 2×2 体系里混在一起，谷结构的规律来自哪一个还不清楚；
  - Sn 系空穴迁移率更高的原因；
  - κ_L；
  - 问题二的全部内容。

## 4 执行顺序与集群分工

| 批次 | 内容 | 产出 |

| 第一批（在跑） | 1-1 的 400–700 K；13_ 的 2-0/2-1 在 jzzn 排队；1-3、1-4、1-7 已完成 | 问题一的输运层齐全 |
| 第二批（**必须补**） | **1-0 能带基准（最优先，PbSb 先做）**；1-5 COHP；1-6 无 SOC 能带与 ε∞ | 现有能带结论哪些成立；回答“反键”；把 6s 惰性与 SOC 分开 |

- **VASP 作业**（15_、13_、ODP）放 **jzzn**，原样用基线 submit.sh（vasp 6.4.3），加 `--qos=regular`。
- **AMSET 作业**留 **hanhai**（amset051 环境已验证，节点内存大；节点共享，要写明 `--mem`）。
- 每种新作业先试跑一个，确认每个自洽步的耗时和基线相当（jzzn 24 核约 800–1000 s/步），再批量提交。
- 提交前把 submit.sh 给用户过目；AutoZT 的代码和模板不改，只改项目自己的提交脚本。
