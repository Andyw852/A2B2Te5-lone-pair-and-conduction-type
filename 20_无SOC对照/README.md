2026-10-23。目的：把“Bi → ε∞ 增大 → POP 耦合减弱”这一链条中**SOC 的贡献**与**6s 惰性的贡献**分开。

### Born 有效电荷（无 SOC，PbSb）

| 离子 | Z\*_xx = Z\*_yy | Z\*_zz |
|---|---:|---:|
| ion 1（Sb） | **9.427** | 3.129 |

**面内 Z\* ≈ 9.43 远大于名义电荷**，是共振成键的直接标志。
无 SOC 下 Z\* 仍很大，说明**共振成键本身不是 SOC 造成的**；但 ε∞ 被 SOC 放大近一倍，
因此 **POP 耦合强度中 SOC 的贡献不可忽略**。

**SOC 使面内 ε∞ 增大约 87%，面外只增大 10%。** 这直接说明：

**此前归因于“孤对电子共振成键”的异常大 ε∞，其中很大一部分其实是 SOC 的贡献**（尤其在面内）。

这与 12_/19_ 中“PbSb 接近 s–p 反转、SOC 显著改变带边”的事实一致：SOC 压小带隙，
按 k·p 关系 ε∞ ≈ 1 + (ħω_p/E_g)² 会显著放大 ε∞。

## 解读（2026-10-23 补充）

**在 PbSb 中，SOC 对面内 Z\* 的影响很小，对 ε∞ 的影响很大。**（其余材料和面外分量见下文“Born 有效电荷”一节：Bi 系的 Z\* 受 SOC 影响更大。） SOC 的 Z\* 取自 08_ 的 OUTCAR（含局域场）：

| PbSb | 有 SOC | 无 SOC | 比值 |
|---|---:|---:|---:|
| Sb Z\*_xx | 10.07 | 9.43 | 0.94 |
| Te（ion 3）Z\*_xx | −5.78 | −5.30 | 0.92 |
| ε∞_xx | 91.80 | 49.06 | 0.53 |
| POP 耦合 C = 1/ε∞ − 1/ε₀（面内） | 0.00754 | 0.01492 | **1.98** |

- **共振成键（反常大的 Z\*）基本与 SOC 无关**，SOC 只让 Z\* 增大约 7%。
- **SOC 把面内 ε∞ 放大了将近一倍，从而把 POP 耦合减半。** POP 散射率正比于 C，所以去掉 SOC 后，PbSb 的 POP 限制迁移率大约会减半。
- 原文写的“POP 耦合 ∝ Z\*²/ε∞”不准确。14_ 用的是 C = 1/ε∞ − 1/ε₀；Z\* 通过 ε₀ − ε∞ 间接进入。
- **SOC 是真实存在的**。迁移率计算本来就应该用含 SOC 的 ε；做无 SOC 对照只是为了区分“6s 惰性”和“SOC”各自贡献了多少，不是要换掉 14_ 的输入。
- **另一个不确定性**：ε∞ 对带隙很敏感，而 PBE+SOC 的带隙偏小（Γ 点附近甚至可能反转，12_ 第 3.2 节）。如果真实带隙更大，含 SOC 的 ε∞ 会比 91.8 小，POP 耦合更强，迁移率更低。1-0 的 HSE 有结果后，可以用 `LCALCEPS`（有限电场，支持杂化泛函）在 PbSb 上复核一次 ε∞。
- **对 14_、18_ 中“B 位 6s 惰性 → ε∞ 增大 → POP 减弱”这条链**：PbSb 的数据说明 ε∞ 的大小主要由 SOC（通过带隙）决定。Bi 比 Sb 的 ε∞ 大，有多少来自 6s 惰性，要看下面三个材料的无 SOC 值。

### 关键结论："Bi 使 ε∞ 增大"主要是 SOC 效应

| 比较 | 有 SOC | 无 SOC |
|---|---:|---:|
| A=Pb：Bi / Sb（ε∞_xx） | 121.33 / 91.80 = **1.32** | 36.29 / 49.06 = **0.74** |
| A=Sn：Bi / Sb（ε∞_xx） | 112.79 / 100.77 = **1.12** | 54.25 / 154.17 = 0.35（**暂缓**：SnSb 无 SOC 待复核，见下） |

**有 SOC 时 Bi 体系的 ε∞ 都比 Sb 大（1.12–1.32 倍）；去掉 SOC 后，Pb 系反号（0.74 倍）。** Sn 系的 0.35 依赖 SnSb 的无 SOC 值，在带隙核对之前不作结论。

这说明 14_/18_ 里"B 位 Bi → ε∞ 增大 → POP 耦合减弱"这条规律，**主要由 SOC 压小带隙驱动**，
而不是 6s 惰性。6s 惰性在无 SOC 下反而表现为 Bi 的 ε∞ **更小**（Bi 的 s–p 反键更弱，
极化率更低），与 COHP 的 Bi-s/Te-p 更弱一致。

### 数据异常需要复核

**Sn₂Sb₂Te₅ 无 SOC 的 ε∞ 异常：面外 1002.53，面内 154.17。** 两个方向都比有 SOC 时大（72.38、100.77），而其余三个材料都是去掉 SOC 后变小。

- ε∞ 是电子部分（离子固定），与声子软模无关；此前“IBRION=7 下有软模”的猜测不成立。作业本身正常结束（LOOP 861 次，介电段和离子段完整），也不是数据损坏。
- 最可能的原因是**去掉 SOC 后 SnSb 的带隙闭合或接近闭合**：ε∞ 的带间部分约按 1/E_g² 增大，带隙趋零时发散。
- 核对方法：直接读该作业已有的 EIGENVAL（每次正常结束都会写，与 `LWAVE`/`LCHARG` 无关），或 OUTCAR 中的 `E-fermi` 与各 k 点本征值、占据数，求带隙并看有无分数占据。**不需要补单点。**
- 核对之前，**SnSb 无 SOC 整行（ε∞、ε_ion 和 Z\*）都暂缓使用**。若带隙确实闭合，这一行就不是“同一电子结构只去掉 SOC”的对照，应标为无效，Sn 系的 Bi/Sb 比较也随之作废。

### SOC 对 Z\* 的影响（暂定，按对调后的归属）

| 材料 | B 位 xx：无 SOC / 有 SOC | 比值 |
|---|---|---:|
| Pb₂Sb₂Te₅ | Sb 9.427 / 10.073 | 0.94 |
| Pb₂Bi₂Te₅ | Bi 7.978 / 10.813 | 0.74 |
| Sn₂Bi₂Te₅ | Bi 8.912 / 10.952 | 0.81 |
| Sn₂Sb₂Te₅ | Sb 11.996 / 11.105 | 1.08（暂缓，见上节） |

- **“Z\* 基本不受 SOC 影响”只在 PbSb 的面内成立。** PbSb 中 Sb 的面外分量从 4.79 降到 3.13（0.65）；Bi 系面内降 20–25%。
- 但 Z\* 的变化仍远小于 ε∞（PbBi：Z\* 0.74–0.81，ε∞_xx 0.30）。无 SOC 时 B 位 Z\* 仍有 8–9.4，远大于名义电荷 +3，**共振成键本身不依赖 SOC**，这一点仍成立。
