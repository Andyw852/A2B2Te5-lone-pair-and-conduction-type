## 3 结论

1. **有序化让三类施主全部变贵，受主不变。**
   - 受主 Pb_Sb：D − O 在 −0.08 到 +0.04 eV 之间，基本不变。
   - 施主：D 中**每一个**位点都比 O 低，Sb_Pb 低 0.41–0.52 eV，Pb 填空位低 1.23–1.79 eV，Sb 填空位低 1.03–1.60 eV。
   - 这些差值都大于 D 内部的位点离散（Sb_Pb 0.10、Pb_Sb 0.12、Sb_on_Vac 0.58、Pb_on_Vac 0.55 eV），所以结论不取决于选哪个位点。按 13_ README 第 2.1 节事先定的规则，**不需要再算其余 3 个 D 母胞**。
   - V_Te 在无序相中也便宜一些（4 个位点 0.03–0.57 eV，中位 0.29 eV，略大于 O 相 3 个位点的离散 0.20 eV），可能因为部分 Te 邻接多个结构空位、配位不足。但它最低仍有 1.07 eV（Te-poor），573 K 下浓度不到 10¹² cm⁻³，比主导缺陷低 7 个量级以上，对 p/n 没有影响。
   - 组成不变的反位对（Sb_Pb + Pb_Sb，与化学势无关）：O 0.75 eV，D 约 0.27 eV（中位数相加）。无序相本身就是阳离子混排的，再交换一对的代价小，符合预期。
2. **有序相（退火后）为净受主，即 p 型。** 在整条共存线上受主 Pb_Sb 都是最低的：Te-rich 时比最低施主低 0.46 eV，Te-poor 时低 0.25 eV。形成能对化学势是线性的，两端成立则整条线成立。净受主 1.6×10¹⁹–3.8×10²⁰ cm⁻³（473–573 K，浅能级近似，上限）。
3. **无序相（退火前）为净施主，即 n 型。**
   - Te-poor：三类施主中位 −0.08 到 0.10 eV，有 5 个位点为负；受主 0.17–0.29 eV。施主占压倒优势。
   - Te-rich：施主中位（Sb_Pb 0.106、Pb_on_Vac 0.135 eV）只比受主（0.163 eV）低约 0.06 eV。符号靠施主的高电荷（Pb 填空位 +2）和最低的几个位点维持，所以这一端的结论较弱，应写成“偏 n 或接近补偿”。
   - 粗估（格气占据 1/(1+e^{E/kT})，473–573 K）：净施主在 Te-rich 端约 2×10²¹，在 Te-poor 端约 1×10²² cm⁻³。这已远超稀薄极限（负形成能），**数值本身没有意义，只用它的符号**。
4. **与文献对照**（Evang 等，Adv. Mater. 34, 2106868 (2022)）。文献认为无序时 Pb、Sb 填空位和 Sb_Pb 容易形成，所以是 n 型；有序后这三者变贵，受主 Pb_Sb 占优，所以是 p 型。本计算在 Pb₂Sb₂Te₅ 上逐项重现：三类施主都随有序化变贵，受主不变，O 净受主，D 净施主。数值上，Sb_Pb 的有序化代价 0.41–0.52 eV，小于 13_ README 记录的文献值 0.7–0.9 eV；填空位施主的代价 1.0–1.8 eV。

## 4 局限

- **只覆盖 5 类缺陷**（1b）。13_ README 第 2 节的第 3 阶段还有 7 类（V_Pb、V_Sb、Te_on_Vac、Pb_Te、Sb_Te、Te_Pb、Te_Sb），旧数据中 Sb_Te 在贫 Te 条件下曾是最低的。所以现在能说的是“在这 5 类中，有序化使施主变贵、受主不变，D 偏 n、O 偏 p”；要说“整体主导缺陷”，需要第 3 阶段。
- 中性形成能 + 浅能级近似，没有带电态和费米能级的反馈。真实的无序相中，施主增多会把费米能级推高，使施主变贵、受主变便宜，从而限制 n 的程度，Te-rich 端可能被补偿到接近本征。所以无序相的数值只取符号和排序。
- 只有一个无序母胞（D_seed1729），每类 4 个位点。种子之间的差异未知，但施主的 D − O 对每个位点都 ≥ 0.41 eV，远大于位点离散。
- PBE-D3，无 SOC。
- 两个母胞都是亚稳的（D 比 PbTe + Sb₂Te₃ 高 0.63 eV/f.u.），用竞争相的化学势是对亚稳相的通行近似。
