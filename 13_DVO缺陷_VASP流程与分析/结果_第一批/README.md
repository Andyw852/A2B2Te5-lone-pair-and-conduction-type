**两种极限都是 PbTe 与 Sb₂Te₃ 共存这条线的两端**：Te-rich 取 Δμ_Te = 0（Te 单质上界），
Te-poor 取 Δμ_Sb = 0（即 Sb-rich）。**母胞在凸包之上，不能用它来定化学势。**

参考相焓（每 f.u.）：

```
dH(PbTe)    = -0.7619 eV/fu
dH(Sb2Te3)  = -0.6302 eV/fu
E(layered) - 2PbTe - Sb2Te3 = +0.1056 eV/fu
```

**母胞相对稳定相的高度（亚稳性）**：

```
O_ordered 每 f.u.  = -591.98689 / 16 = -36.99918 eV
2PbTe + Sb2Te3     = 2×(-8.30446) + (-20.58050) = -37.18942 eV
→ rocksalt 母胞比 2PbTe + Sb2Te3 高 0.190 eV/f.u.（约 21 meV/原子）
9 原子层状 Pb2Sb2Te5 = -37.08380 eV/f.u.
→ 母胞比层状相高 0.085 eV/f.u.
```

**注意**：上文参考相焓里的 `+0.106 eV/f.u.` 是**层状参考相相对 2PbTe + Sb₂Te₃** 的值，
**不是母胞的**。母胞自身的亚稳性是 +0.190 eV/f.u.

## 3. 三条结论

### 3.1 排序在两种化学势极限下一致

```
Pb_Sb (0.14-0.25)  <<  Sb_Pb (0.50-0.60)  <<  Pb_on_Vac (1.49-1.70) < Sb_on_Vac (1.48-1.79) ≈ V_Te (1.58-1.99)
```

**Pb_Sb 是最低形成能缺陷，比第二名 Sb_Pb 低 0.25–0.46 eV**（Te-rich 差 0.462 eV、Te-poor 差 0.252 eV）。

### 3.2 浅能级近似下的净受主浓度（有序相一侧）

`DVO_结论摘要.json` 的 `nominal_net_donor_minus_acceptor_cm3` 字段（全电离、中性形成能、按 Σq·c）：

| 化学势条件 | 473 K | 573 K |
|---|---:|---:|
| **Te-rich** | **2.1×10²⁰ cm⁻³** | **3.8×10²⁰ cm⁻³** |
| **Te-poor** | **1.6×10¹⁹ cm⁻³** | **4.5×10¹⁹ cm⁻³** |

**都是净受主，几乎全部来自 Pb_Sb。**

两条局限必须记住：

1. **接近稀薄近似边缘**：Pb_Sb 形成能只有 0.14–0.25 eV，对应 Sb 位上 0.2–6% 被占；
2. **浓度是上限**：用中性形成能，忽略了费米能级对带电缺陷的反馈。

**能用的结论是符号和排序**：有序相一侧明显是净受主，与"转 p 型"一致。
但**转变本身要等 D 族（无序母胞）的同一张表**——回答"退火前为什么是 n 型"需要它，目前未完成。

### 3.3 V_Te 形成能最高，不参与排序的前列

**V_Te 现在有 2 个位点完成**（s01、s02）：Te-rich 1.793–1.845 eV、Te-poor 1.583–1.635 eV，
**比 Pb_Sb 高 1.3–1.6 eV**，仍是五类缺陷中最高的。位点间离散仅 ±26 meV，不影响排序。

第三个位点 s03 的 static 已完成（`V_Te__s03` 计入 13 个 DONE 之一）；s01 目前在跑 static。
全部位点完成后重跑 collect/analyze 即可，**结论不会变**。

## 4. 关于“倾向 p 型”的正确理解

`DVO_结论摘要.json` 里的 `"p"` **不是带电态计算的结果**，而是：

- `notes[1]`："tendency uses electron counting (Pb2+, Sb3+, Te2-) with full ionisation;
  it is the literature-level classification, not a carrier prediction"

即按 Pb²⁺/Sb³⁺/Te²⁻ 全电离的电子计数，取形成能最低缺陷的名义电荷符号。
**它是文献级的定性分类，不是载流子浓度预测。**

`charged_neutrality` 字段当前为空 `{}`，因为本批没有带电缺陷作业、也没有 `--dos`。
问题二按既定方案使用**浅能级近似（Σq·c）**，不新开带电缺陷计算。

## 5. 填位原子的位移（交叉验证“填入阳离子空位”）

| 缺陷 | `nearest_atom_to_filled_site_A` |
|---|---:|
| Pb_on_Vac | **0.00122 Å** |
| Sb_on_Vac | **0.00008 Å** |

填进空位的 Pb/Sb 几乎不动 → 证实这两类缺陷是**填入阳离子结构空位**（Pb₂Sb₂Te₅ 阳离子位约 20% 为空），
不是填进 Te 空位。它们是施主（名义 +2/+3），是无序相 n 型的候选来源。
