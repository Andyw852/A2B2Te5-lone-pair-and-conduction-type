## 3. 三条结论

### 3.1 排序在两种化学势极限下一致

```
Pb_Sb (0.14-0.25)  <<  Sb_Pb (0.50-0.60)  <<  Pb_on_Vac ≈ Sb_on_Vac ≈ V_Te (1.5-1.8)
```

**Pb_Sb 是最低形成能缺陷，比第二名 Sb_Pb 低 0.25–0.36 eV。**

### 3.2 有序相里受主占优 → 与“有序化后转 p 型”一致

O_ordered 中受主 Pb_Sb 形成能最低（0.14–0.25 eV），所有施主都在 0.50 eV 以上。
这是“退火（有序化）后材料转 p 型”的直接微观解释。

**但这只是有序相一侧。** 回答“退火前为什么是 n 型”需要 D 族（无序母胞）的同一张表，目前未完成。

### 3.3 V_Te 形成能最高，不参与排序的前列

V_Te 在两种极限下均为 1.63–1.84 eV，比 Pb_Sb 高 1.4–1.6 eV。
因此 **V_Te s01/s02 两个位点尚未算完不影响本批排序**，等它们完成后补入即可（见 `../` 的 STATUS）。

## 4. 关于“倾向 p 型”的正确理解

`DVO_结论摘要.json` 里的 `"p"` **不是带电态计算的结果**，而是：

- `notes[1]`："tendency uses electron counting (Pb2+, Sb3+, Te2-) with full ionisation;
  it is the literature-level classification, not a carrier prediction"

即按 Pb²⁺/Sb³⁺/Te²⁻ 全电离的电子计数，取形成能最低缺陷的名义电荷符号。
**它是文献级的定性分类，不是载流子浓度预测。**

`charged_neutrality` 字段当前为空 `{}`，因为本批没有带电缺陷作业、也没有 `--dos`。
问题二按既定方案使用**浅能级近似（Σq·c）**，不新开带电缺陷计算。

## 5. 填位原子的位移（交叉验证“填入阳离子空位”）

| 缺陷 | `nearest_atom_to_filled_site_A` |
|---|---:|
| Pb_on_Vac | **0.00122 Å** |
| Sb_on_Vac | **0.00008 Å** |

填进空位的 Pb/Sb 几乎不动 → 证实这两类缺陷是**填入阳离子结构空位**（Pb₂Sb₂Te₅ 阳离子位约 20% 为空），
不是填进 Te 空位。它们是施主（名义 +2/+3），是无序相 n 型的候选来源。
