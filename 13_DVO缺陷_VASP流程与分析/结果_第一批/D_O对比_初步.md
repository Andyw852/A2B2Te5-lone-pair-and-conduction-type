# D（无序）vs O（有序）缺陷形成能对比

2026-10-27。第一批 D 族数据基本完成。本文件给出 **D–O 对比与“退火前 n 型、退火后 p 型”的定量解释**。

## 1. 两个母胞的参考能量（144 原子，组分相同 Pb32Sb32Te80）

| 母胞 | E(static) | 每 f.u. | 体积 |
|---|---:|---:|---:|
| **O_ordered** | −591.98689 | −36.9991 | 4732.10 Å³ |
| **D_seed1729** | −584.95823 | −36.5598 | 4833.50 Å³ |
| **差 D−O** | **+7.0287 eV** | **+0.439 eV/f.u.** | **+101.4 Å³ (+2.1%)** |

**无序相比有序相高 0.439 eV/f.u.**（阳离子无序的有序化能），体积大 2.1%。
形成能对比用**各自的母胞**作参考，这个 7.03 eV 的差在形成能中被消掉。

## 2. 完整的 D–O 对比（Te-rich）

（Te-poor 条件同向：Pb_Sb 0.247→0.258，Sb_Pb 0.499→0.085，Pb_on_Vac 1.489→0.256，Sb_on_Vac 1.475→0.447）

## 3. 核心结论：三类施主全部大幅变便宜，受主不变

```
               O（有序）    D（无序）    D-O       位点离散
Pb_Sb（受主）    +0.337      +0.260~+0.367  +0.011    ±0.054   <- 无变化
Sb_Pb（+1）      +0.409      -0.085/-0.005  -0.454    ±0.040   <- 剧降
Pb_on_Vac（+2）  -3.023      -4.257         -1.233    —        <- 降幅最大
Sb_on_Vac（+3）  -3.127      -4.155         -1.028    —        <- 剧降
```

**（dE_raw 为相对各自母胞的总能差，单位 eV）**

### 3.1 物理图像

无序相的**阳离子子晶格本来就是随机占据的**：
- 把 Sb 放到 Pb 位（`Sb_Pb`）几乎不额外花能量（dE_raw ≈ −0.005 eV）；
- 把 Pb/Sb 填进阳离子空位（`Pb_on_Vac`/`Sb_on_Vac`）也不需要“破坏有序排列”，代价大降。

有序相里，上述操作都会破坏有序排列，代价 0.4–1.2 eV。

### 3.2 形成能排序在两种相中反转

| 相 | 排序（由低到高） | 主导类型 |
|---|---|---|
| **O（有序）** | **Pb_Sb 0.142** << Sb_Pb 0.604 << Pb_on_Vac 1.699 ≈ Sb_on_Vac 1.790 | **受主 → p 型** |
| **D（无序）** | **Sb_Pb 0.150 ≈ Pb_Sb 0.153** << Pb_on_Vac 0.466 < Sb_on_Vac 0.762 | **施主供给大幅增加 → n 型** |

**关键**：在 D 相，`Sb_Pb`（0.150）已几乎追平受主 `Pb_Sb`（0.153），
而 `Pb_on_Vac`（0.466）与 `Sb_on_Vac`（0.762）从“极贵”（1.7–1.8 eV）变成“可用”。

### 3.3 对“退火前 n 型、退火后 p 型”的定量解释

**退火（有序化）的作用 = 把施主“关掉”，受主不受影响：**

| 缺陷类型 | D−O 变化 | 效果 |
|---|---:|---|
| 受主 `Pb_Sb` | **+0.011 eV** | 不变 |
| 施主 `Sb_Pb` | **−0.454 eV** | 无序相便宜 → 施主供给增加 |
| 施主 `Pb_on_Vac` | **−1.233 eV** | 同上（幅度最大） |
| 施主 `Sb_on_Vac` | **−1.028 eV** | 同上 |

**三类独立施主给出同向、大幅的效应（0.45–1.23 eV），而受主几乎完全不变（0.011 eV）。**
这就是“无序相施主主导 → n 型；有序化后施主变贵、受主独大 → p 型”的微观定量版本。

### 3.4 稳健性

- 施主效应（0.45–1.23 eV）**远大于**位点离散（0.04–0.10 eV），信噪比 > 4；
- 三类施主**独立**给出同向结果；
- 受主变化（+0.011 eV）**小于**其自身位点离散（0.054 eV），即“无效应”。

## 4. 待补

1. **V_Te（+2）在 D 相**：4 个位点在弛豫（7–11 步）；O 相为 1.793–1.990 eV（最高），预计 D 相也会降；
2. **Pb_on_Vac / Sb_on_Vac 的更多位点**：目前各 1 个，其余在 static；
3. **Pb_Sb 的 D 第 4 位点**（s02）在弛豫。

以上补充不改变本文件的结论方向（施主效应远大于位点离散）。
