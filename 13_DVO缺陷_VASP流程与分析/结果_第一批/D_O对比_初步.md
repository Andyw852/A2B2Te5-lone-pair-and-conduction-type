# D（无序）vs O（有序）缺陷形成能对比

2026-10-27。第一批 D 族已完成 **13/20**。本文件给出 **D–O 对比与“退火前 n 型、退火后 p 型”的定量解释**。

## 1. 两个母胞的参考能量（144 原子，组分相同 Pb32Sb32Te80）

| 母胞 | E(static) | 每 f.u. | 体积 |
|---|---:|---:|---:|
| **O_ordered** | −591.98689 | −36.9991 | 4732.10 Å³ |
| **D_seed1729** | −584.95823 | −36.5598 | 4833.50 Å³ |
| **差 D−O** | **+7.0287 eV** | **+0.439 eV/f.u.** | **+101.4 Å³ (+2.1%)** |

**无序相比有序相高 0.439 eV/f.u.**（无序的有序化能），体积大 2.1%。
形成能对比用**各自的母胞**作参考，这个 7.03 eV 的差在形成能中被消掉。

## 2. D–O 对比（Te-rich）—— 以“范围 + 最坏情况”表述

| 缺陷 | 性质 | O（有序） | D n | **D 位点范围** | D 中位 | **D−O 中位** | **D−O 最坏** |
|---|---|---:|---:|---|---:|---:|---:|
| **Pb_Sb** | **受主 (−1)** | 0.142 | 3 | 0.065–0.172 | 0.153 | **+0.011** | +0.030 |

（Te-poor 条件同向：Pb_Sb 0.247→0.258，Sb_Pb 0.499→0.085，Pb_on_Vac 1.489→0.256，Sb_on_Vac 1.475→0.447）

## 3. 三个层次的结论

### 3.1 一类施主出现负形成能（最强证据）

```
Pb_on_Vac 在 D 相：4 个位点的形成能 = -0.088, ... , +0.466 eV
                     最小值 -0.088 eV < 0
```

**负形成能意味着该位点上的 Pb 填入阳离子空位是热力学自发的。**
在无序相中，阳离子空位数量约占阳离子位的 20%，因此施主供给**不受热激活限制，而受空位数量限制**。

**⚠ 稀薄近似在此失效**：`DVO_结论摘要.json` 的 `notes` 明确写：
> negative_Ef_present: the dilute limit fails for that family/condition; report ranking only

即：出现负形成能时，不能按 `exp(−Ef/kT)` 外推浓度（会给出超过空位数量的荒谬值）。
**正确说法是“形成近乎自发、浓度受空位数量限制”，而不是给出一个具体浓度数字。**

### 3.2 三类施主全部大幅变便宜，受主不变

```
主要证据（最坏情况下的 D-O，eV）：
  Pb_Sb（受主）：  +0.030   <- 无变化（小于其位点离散 0.107）
  Sb_Pb：          -0.414   <- 位点离散仅 0.104，信噪比 4.7，最可靠
  Pb_on_Vac：      -1.233   <- 且部分位点为负形成能
  Sb_on_Vac：      -1.028
```

### 3.3 物理图像

无序相的**阳离子子晶格本来就是随机占据的**：
- 把 Sb 放到 Pb 位（`Sb_Pb`）几乎不额外花能量（dE_raw ≈ −0.005 eV）；
- 把 Pb/Sb 填进阳离子空位（`Pb_on_Vac`/`Sb_on_Vac`）不需要“破坏有序排列”，某些位置甚至是负能量。

有序相里，上述操作都会破坏有序排列，代价 0.4–1.2 eV。

### 3.4 形成能排序在两种相中反转

| 相 | 排序（由低到高） | 主导类型 |
|---|---|---|
| **O（有序）** | **Pb_Sb 0.142** << Sb_Pb 0.604 << Pb_on_Vac 1.699 ≈ Sb_on_Vac 1.790 | **受主 → p 型** |
| **D（无序）** | **Sb_Pb 0.110 ≈ Pb_on_Vac 0.136 ≈ Pb_Sb 0.153** < Sb_on_Vac 0.505 | **施主完全主导 → n 型** |

**在 D 相，`Sb_Pb`（0.110）和 `Pb_on_Vac`（0.136）都低于受主 `Pb_Sb`（0.153）。**

### 3.5 对“退火前 n 型、退火后 p 型”的定量解释

| 缺陷类型 | D−O（最坏情况） | 效果 |
|---|---:|---|
| 受主 `Pb_Sb` | **+0.030 eV**（小于其离散 0.107） | **无变化** |
| 施主 `Sb_Pb` | **−0.414 eV**（离散 0.104） | 无序相便宜 → 施主供给增加 |
| 施主 `Pb_on_Vac` | **−1.233 eV**（离散 0.554） | 同上，部分位点负形成能 |
| 施主 `Sb_on_Vac` | **−1.028 eV**（离散 0.576） | 同上 |

**三类独立施主同向大幅下降，受主几乎完全不变** —— 这是“无序相施主主导 → n 型；
有序化后施主变贵、受主独大 → p 型”的定量微观机制。

## 4. 稳健性与局限（诚实说明）

**稳健的部分**：
- `Sb_Pb` 位点离散 0.104 eV、D−O = −0.494 eV → **信噪比 4.7，最可靠**；
- 三类施主独立同向；
- 即使取最坏情况，三类施主仍分别低 0.41 / 1.23 / 1.03 eV；
- `Pb_on_Vac` 出现负形成能，是“无序相施主自发形成”的直接证据。

**局限**：
- `Pb_on_Vac`/`Sb_on_Vac` 的**位点离散大（0.55 / 0.58 eV）**，定量值应以范围报告；
- **O 相各类缺陷只有 1 个位点**，其离散未知，是当前最大统计短板；
- `Pb_on_Vac` 的负形成能导致**稀薄近似失效**，不能外推浓度。
