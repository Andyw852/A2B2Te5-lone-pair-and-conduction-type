## 3. D–O 对比（Te-poor）—— 施主几乎“零成本”

| 缺陷 | O（有序） | **D 位点范围** | **D 中位** | D−O（中位） |
|---|---:|---|---:|---:|
| Pb_Sb（受主） | 0.247 | 0.170–0.288 | **+0.268** | +0.020 |
| **Sb_Pb** | 0.499 | **−0.019 – +0.085** | **+0.001** | **−0.498** |
| **Pb_on_Vac** | 1.489 | **−0.298 – +0.256** | **−0.075** | **−1.564** |
| **Sb_on_Vac** | 1.475 | **−0.130 – +0.447** | **+0.096** | **−1.379** |
| V_Te | 1.583–1.780 | 1.457–1.608 | 1.532 | −0.103 |

**注意**：D−O 中位差值在 Te-rich 与 Te-poor 下**完全相同**（0.020 / −0.498 / −1.564 / −1.379 / −0.103）。
这是必然的——化学势项在 D−O 相减时被消掉，所以 **D−O 是化学势无关的纯结构效应**。

### 3.1 Te-poor 下施主形成几乎无成本

在 Te-poor（富金属）条件下，无序相三类施主的中位数：

```
Sb_Pb      +0.001 eV   ≈ 0
Pb_on_Vac  -0.075 eV   < 0
Sb_on_Vac  +0.096 eV   ≈ 0
```

而受主 `Pb_Sb` 升到 **+0.268 eV**。**施主与受主的差距达到 0.27–0.34 eV。**

## 4. 决定性证据：只有“阳离子位”的缺陷受影响

| 位置类型 | 缺陷 | D−O（中位） | 效应 |
|---|---|---:|---|
| **阳离子位（替代）** | Pb_Sb（受主） | +0.020 | **不变** |
| | Sb_Pb（施主） | −0.498 | **剧降** |
| **阳离子空位（填充）** | Pb_on_Vac（施主） | −1.564 | **剧降** |
| | Sb_on_Vac（施主） | −1.379 | **剧降** |
| **阴离子空位** | **V_Te（施主）** | **−0.103** | **几乎不变** |

**凡是涉及阳离子子晶格的缺陷在无序相都大幅变便宜（0.50–1.56 eV）；
唯一不涉及阳离子子晶格的 V_Te 只降 0.103 eV。**

### 4.1 这是一个内部一致性检验

阳离子无序**只应该影响阳离子位的缺陷**。V_Te 的 D−O ≈ −0.1 eV 正是这个预期的定量体现
（剩余 0.1 eV 可能来自无序相体积大 2.1% 带来的轻微应变释放）。

**这个对照大幅增强了机制的可信度**：不是“所有缺陷在无序相都变便宜”，而是**特定位置**的缺陷变便宜。

### 4.2 物理图像

无序相的**阳离子子晶格本来就是随机占据的**：
- 把 Sb 放到 Pb 位（`Sb_Pb`）几乎不额外花能量；
- 把 Pb/Sb 填进阳离子空位（`Pb_on_Vac`/`Sb_on_Vac`）不需要“破坏有序排列”，某些位置甚至负形成能。

有序相里，上述操作都会破坏有序排列，代价 0.4–1.2 eV。
而 Te 空位在两种相里的局部环境相似，因此几乎不受影响。

## 5. 形成能排序在两种相中反转

| 相 | 排序（由低到高，Te-rich） | 主导类型 |
|---|---|---|
| **O（有序）** | **Pb_Sb 0.142** << Sb_Pb 0.604 << Pb_on_Vac 1.699 ≈ Sb_on_Vac 1.790 ≈ V_Te 1.844 | **受主 → p 型** |
| **D（无序）** | **Sb_Pb 0.106 ≈ Pb_on_Vac 0.136 ≈ Pb_Sb 0.163** < Sb_on_Vac 0.411 << V_Te 1.742 | **阳离子位施主主导 → n 型** |

**Te-poor 下更极端**：Sb_Pb 0.001、Pb_on_Vac −0.075、Sb_on_Vac 0.096 vs 受主 Pb_Sb 0.268。

## 6. 负形成能与稀薄近似的失效（重要技术约束）

多个位点出现负形成能：

```
Te-rich : Pb_on_Vac  最小值 -0.088 eV
Te-poor : Pb_on_Vac  最小值 -0.298 eV、中位 -0.075 eV
          Sb_Pb      最小值 -0.019 eV
          Sb_on_Vac  最小值 -0.130 eV
```

**负形成能意味着该位点上填阳离子空位是热力学自发的。**
无序相中阳离子空位约占阳离子位的 20%，因此施主供给**不受热激活限制，而受空位数量限制**。

**⚠ 稀薄近似在此失效**：`DVO_结论摘要.json` 的 `notes` 明确写：
> negative_Ef_present: the dilute limit fails for that family/condition; report ranking only

**正确说法是“形成近乎自发、浓度受空位数量限制”，而不是给出一个具体浓度数字。**

## 7. 稳健性与局限（诚实说明）

**稳健的部分**：
- `Sb_Pb` 4 个位点、离散 0.105 eV、D−O = −0.498 eV → **信噪比 4.7，最可靠**；
- 三类阳离子位施主独立同向；
- **V_Te 作为“阴性对照”只降 0.103 eV**，证明效应是位置选择性的；
- **D−O 与化学势无关**（Te-rich 与 Te-poor 给出完全相同的差值），是纯结构效应；
- 多个位点出现负形成能，是“无序相施主自发形成”的直接证据。

**局限**：
- `Pb_on_Vac` 位点离散 0.554 eV、`Sb_on_Vac` 0.576 eV，定量值应以范围报告；
- **O 相各类缺陷只有 1 个位点**，其离散未知，是当前最大统计短板；
- 负形成能导致**稀薄近似失效**，不能外推浓度；
- V_Te 在 D 相只有 2 个位点（另 2 个仍在算）。
