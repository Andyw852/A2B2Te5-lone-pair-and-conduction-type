# 散射机制分项迁移率（密网格 AMSET）

脚本：[`10_脚本/scattering_mobility.py`](../10_脚本/scattering_mobility.py)。

```bash
python 10_脚本/scattering_mobility.py .
```

- **输入参数表** `散射输入参数.csv` 每次都会重写，包括：ε∞、ε₀、POP 耦合 (1/ε∞ − 1/ε₀)、ω_LO、Cᵢⱼ、带边形变势 E1、剪刀后带隙，以及由密网格 BoltzTraP2 得到的面内电导质量 m\*_c。
- **迁移率表和图**：只有当集群上的密网格全量结果放进 `密网格AMSET/<材料>/transport.json` 之后才会生成。没有结果的材料自动跳过。

**旧的 12×12×2 粗网格结果已作废并删除**：它比密网格结果低 3–4 倍，原因见第 3 节。

## 1 算了哪些机制

| 机制 | 输入 | 来源 |
|---|---|---|
| ADP 声学形变势 | 逐带形变势 + 完整弹性张量 | `05_SOC_AMSET补算/*/03_SOC形变势/deformation.h5`（PBE-D3+SOC，12×12×2 应变单点） |
| POP 极性光学声子 | ε∞、ε₀ + 一个等效 LO 频率（1.9–2.15 THz） | `08_介电复核` 的 SOC DFPT。DFPT 力常数不含 D3，补上后 ε₀ 变化 <1%、POP 耦合变化 0.3%，见 [18_](../18_ZT参数与孤对电子/README.md) |
| IMP 电离杂质 | ε₀ 屏蔽；补偿因子和缺陷电荷取 AMSET 默认值 | settings |

- 总迁移率是在每个 k 态上先把三种散射率相加后得到的，不能用三个分项按 1/μ 相加来还原。
- 迁移率只用多数载流子的能带计算（AMSET 默认 `separate_mobility: true`），不受双极效应影响。
- **POP 在所有情况下都占主导**：总迁移率与 POP 分项之比为 0.67–0.89；IMP 分项比 POP 大 30–70 倍，因为 ε₀（300–390）把杂质散射屏蔽掉了。

**没有包括的机制**

| 机制 | 处理 |
|---|---|
| 非极性光学声子（ODP） | 可以用 AutoZT 的冻声子方法算 Γ 点拉曼模（4 A1g + 4 Eg）的形变势，计划见 19_ 计算 1-7。A1g 模包含 B 位偏心的坐标 |
| 谷间散射（IVS） | AutoZT 的两种 IVS（冻声子 K↔K′、QE DFPT）都只支持无 SOC，这四种材料必须带 SOC，所以不算。影响方向：谷越多，迁移率被高估得越多（Sb 系空穴、Sn 系电子） |
| 无序与缺陷本身的散射、晶界 | 不算 |
| 压电散射 | 结构有反演中心，压电张量为零 |

## 2 密网格计算的选带规则

AMSET 的 `amset wave` 和 `amset run` 都按 `energy_cutoff` 选带：只要某条带在 [VBM − e, CBM + e] 内有能量就保留，用的是未加剪刀的 DFT 带边。用 [`10_脚本/amset_band_window.py`](../10_脚本/amset_band_window.py) 核对：

- 在 e = 1.5 eV（默认值，也是形变势计算用的值）下，密网格选出的带与旧 `deformation.h5` 的带号**逐个重合**：PbSb 53–82、PbBi 67–100、SnSb 57–82、SnBi 73–102。四个材料的 wave 实测选带与此一致。
- AMSET 只检查形变势的带**数**，不检查带号，所以带号是否重合要自己核对。
- 结论：用 `-e 1.5` 重跑 wave，`amset run` 用默认 `energy_cutoff`，就可以直接沿用旧的形变势。

## 3 网格收敛测试（PbSb、SnSb；300 K，±1e19，面内）

`interpolation_factor` 取 0.5、1、2，其余设置与旧计算完全相同。

- **旧结果低 3–4 倍，原因是 DFT 输入太粗，不是插值网格不够密。** f0.5 与旧计算的插值网格大小几乎相同，星函数数目也相近（2744 对 2880），只换了 DFT 输入，结果就差了 3–4 倍。
- **S 也印证了这一点。** ±1e19 下，新 AMSET 的 S 与密网格 BoltzTraP2 的平均偏差为 10 µV/K，旧计算为 33 µV/K。
- **全量计算用 factor 1。** f2 相对 f1 变化 2–5%，Sn/Pb 比变化 0.03，满足事先定的判据。但迁移率每次加密都在下降，SnSb 空穴和 PbSb 电子的降幅没有明显变小。按网格间距外推（三个点，只作估计）：
  - **f1 的绝对迁移率是偏高的估计，可能高 5–25%**；
  - Sn/Pb 空穴迁移率比应写成 1.4–1.6，方向（Sn > Pb）稳定；电子迁移率 Pb 系更高，Pb/Sn 比为 1.35–1.5；
  - 电子迁移率 Sn 系更低，来自更重的电导质量（0.18–0.24 对 0.11–0.16 mₑ）。POP 是小 q 的谷内散射，谷数几乎不影响它。
- PbSb 的剪刀修正是 −0.154 eV（PBE 0.219 → 0.065 eV），对应 12_ 中 Γ 点带序的问题，与网格无关。

## 5 密网格结果（300 K，面内，四个材料）

![300 K 分项迁移率](分项迁移率_四材料_300K.png)

总迁移率（cm²/V·s）：

| 净浓度 | PbSb | PbBi | SnSb | SnBi |
|---|---:|---:|---:|---:|
| p 1e19 | 1118 | 1357 | 1816 | 1530 |
| p 1e20 | 881 | 940 | 1385 | 1093 |
| n 1e19 | 1029 | 997 | 667 | 466 |
| n 1e20 | 692 | 679 | 446 | 479 |

**2×2 对比（1e19）**

| | p 型 | n 型 |
|---|---|---|
| A 位 Pb→Sn（B=Sb / B=Bi） | 1.62 / 1.13 | 0.65 / 0.47 |
| B 位 Sb→Bi（A=Pb / A=Sn） | 1.21 / 0.84 | 0.97 / 0.70 |

**用什么解释**：POP 主导，所以迁移率主要由两个量决定：POP 耦合强度 C = 1/ε∞ − 1/ε₀，以及电导质量 m\*_c。

| | PbSb | PbBi | SnSb | SnBi |
|---|---:|---:|---:|---:|
| ε∞（面内） | 92 | 121 | 101 | 113 |
| C | 0.0075 | 0.0053 | 0.0074 | 0.0061 |
| 空穴 m\*_c，1e19 / 1e20（mₑ） | 0.088 / 0.127 | 0.104 / 0.125 | 0.084 / 0.096 | 0.096 / 0.118 |
| 电子 m\*_c，1e19 / 1e20（mₑ） | 0.112 / 0.182 | 0.160 / 0.212 | 0.181 / 0.261 | 0.236 / 0.278 |

- **电子**：POP 分项迁移率与 1/(C·m\*_c^1.25) 成正比，四个材料的误差约 10%。Sn 系电子迁移率低，是因为电导质量重（0.18–0.24 对 0.11–0.16 mₑ）；Bi 让 ε∞ 增大、POP 耦合变弱，部分抵消了它更重的质量。
- **空穴，1e20**：同样由 C 和 m\*_c 解释，误差约 10%。
- **空穴，1e19**：Sn 系比 C 和 m\*_c 的预测高 25–40%，原因还没有确定。PbSb 在 1e19 受双极效应影响，电导质量偏小。一个可能的原因是：POP 是谷内散射，散射率取决于单个谷的态密度，而 Sn 系价带谷在一般 k 点上、单谷质量较小。
- **所谓 A–B“交互作用”，其实是 ε∞ 的变化幅度不同**：
  - 在 Pb 系里，Sb→Bi 使 ε∞ 增大 32%（92→121），POP 耦合减弱 29%，盖过了空穴质量的增加，迁移率升高（×1.21）。
  - 在 Sn 系里，ε∞ 只增大 12%（101→113），耦合只减弱 17%，抵不过质量增加，迁移率下降（×0.84）。
- **与孤对电子的联系（2026-10-23 修正）**：原先把“B 位 Bi 使 ε∞ 增大”归因于 6s 惰性。无 SOC 对照（[20_](../20_无SOC对照/README.md)）推翻了这一点：Pb 系去掉 SOC 后，Bi 的 ε∞ 反而比 Sb 小（36 对 49），有 SOC 时 ε∞ 是无 SOC 的 1.9–3.3 倍。所以 Bi 带来的 ε∞ 增大和 POP 减弱主要是 6p 的 SOC 造成的（Bi 系中 SOC 缩小带隙）。反常大的 Born 有效电荷（共振成键）去掉 SOC 后仍远大于名义电荷（PbSb 降 6%，Bi 系降 19–26%）。SnSb 去掉 SOC 后带隙只剩 30 meV，无 SOC 数据作废，Sn 系无法比较。
- **各向异性**：Pb 系空穴的面外迁移率约为面内的 1/3，Sn 系为 0.6–0.7。PbBi 的电子面外迁移率只有面内的 5–16%。
- **POP 在四个材料、两种载流子中都占主导**，IMP 分项比 POP 大 8–115 倍。
- 绝对迁移率可能偏高 5–25%（第 3 节）；材料之间的比值受网格收敛的影响较小。

## 4 密网格全量结果放在哪里

四个材料统一用精简网格：300–700 K（每 100 K）× ±1e18、±1e19、±1e20。把集群上的结果复制到 `密网格AMSET/<材料>/`，文件名为 `transport*.json`，并附上对应的 settings.yaml。然后重跑本脚本和 `10_脚本/zt_parameters.py`。按温度拆成多个作业的结果会自动合并，要求浓度列表相同、温度不重复。

**为什么不算全表**：POP 的非弹性散射率要对每个（浓度, 温度）组合单独计算。Sb 系在 128 进程下每个组合约 0.45 h，12 个浓度 × 17 个温度要将近 95 h；而 hanhai 的墙钟上限是 24 h，用户不能延长，AMSET 也只在全部算完后才写结果。精简网格是 30 个组合，按温度拆成 300–500 K 和 600–700 K 两个作业，每个约 7–10 h。

运行状态见 [19_](../19_两个问题的计算方案/README.md)。
