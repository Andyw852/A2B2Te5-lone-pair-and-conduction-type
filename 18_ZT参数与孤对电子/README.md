# ZT 各参数与孤对电子：已有数据能说什么

2026-10-18。zT = S²σT / (κₑ + κ_L)，σ = n e μ。本目录把讨论从 S 扩展到 ZT 的全部成分。所有数值都来自仓库里已有的计算输出，**没有运行新的 DFT**。脚本：[`10_脚本/zt_parameters.py`](../10_脚本/zt_parameters.py)。

```bash
python 10_脚本/zt_parameters.py .     # 约 2 s；读 08 的 DFPT OUTCAR、05 的弹性张量、BoltzTraP2、12_/14_/15_ 的结果
python 10_脚本/d3_dfpt_check.py .     # 约 1 s；需 pip install dftd3；D3 对 DFPT 声子量的影响
python 10_脚本/bt2_local.py . Pb2Sb2Te5   # 每个材料约 5 min；需 pip install BoltzTraP2 ase；双极热导分解与带隙敏感性
```

## 2 晶格与成键参数（`晶格与成键参数.csv`）

| | Pb₂Sb₂Te₅ | Pb₂Bi₂Te₅ | Sn₂Sb₂Te₅ | Sn₂Bi₂Te₅ |

| Z\*_Te 面内 / 面外（名义 −2） | −6.7 / −5.1 | −7.2 / −5.1 | −7.5 / −5.2 | −7.5 / −5.2 |

| 平均声速 v_m（m/s） | 2125 | 1982 | 2296 | 2134 |
| θ_D（K） | 198 | 183 | 217 | 199 |
| Cahill κ_min（W/m·K） | 0.78 | 0.71 | 0.85 | 0.78 |
| 由泊松比估计的 γ | 1.44 | 1.47 | 1.39 | 1.42 |

- **Z\* 和 ε∞ 异常大**：这是 s² 电子不参与成键、p 电子形成共振（亚稳价）键的典型标志（Wuttig、Raty 等人的判据）。四种材料都有，差别只有约 10–15%，所以它说明的是这一族材料共同的键型，不能用来解释材料之间的差异。
- **B 位偏心刚度**：由 Γ 点 DFPT 的本征值和本征矢重建力常数矩阵，再沿 15_ 中“B 位回到八面体中心”的位移方向（Te 冻结）计算得到。它给出了 15_ 里 λ=0 计算的**谐近似预测**：λ=0 与 λ=1 的能量差应约为 140–190 meV/胞。如果 DFT 实际值明显偏小，说明沿这个坐标的势能面强烈非谐，甚至接近双势阱，这正是孤对电子立体化学活性的特征，也直接关系到低 κ_L。所以 λ 扫描的总能本身就是一个非谐性测量，不需要额外计算。
- **D3 与 DFPT 的口径（已量化，不需要重算）**：08 的 DFPT 没有加 IVDW，因为 VASP 的 DFPT 不支持 vdW 修正。D3 只依赖原子坐标，不进入 KS 势，所以在同一结构上 ε∞ 和 Z\* **完全**不受影响。但 D3 的二阶导数会进入 Γ 点力常数，所以 ε_ion、ε₀、光学模频率、pop_frequency 和上面的 B 位偏心刚度，严格说都是“PBE 力常数 + PBE-D3 结构”下的值。
  - 方法：[`10_脚本/d3_dfpt_check.py`](../10_脚本/d3_dfpt_check.py) 用有限差分算出 D3(BJ) 的 Hessian（IVDW=12 参数，不含三体项，截断半径与 VASP 相同），加到由 Γ 本征对重建的力常数上。重建本身复现了 VASP 的 ε_ion（差 ≤0.1）和 settings 中的 pop_frequency（差 ≤0.005 THz）。
  - 结果（`D3对DFPT声子量的影响.csv`）：D3 Hessian 的最大元只有 0.03–0.04 eV/Å²，不到 PBE 力常数的 0.6%。加入后 ε₀(xx) 增加 0.7–0.8%，POP 耦合 (1/ε∞ − 1/ε₀) 增加 0.3%，pop_frequency 降低 0.2–0.5%，最软光学模升高 0.5–0.8%，B 位偏心刚度降低 0.5%（谐近似回中能量少 0.7–1.0 meV/胞）。
  - 原因：每胞 −3.9 eV 的 D3 能量几乎全部作用在晶格常数和层间距上，这部分已经体现在结构里；它对 Γ 点光学位移的曲率很小。
  - 与 15_ λ=0 的总能比较时，DFT 总能本来就包含 D3，用 CSV 中的 PBE+D3 列作谐近似预测即可。
- **κ_L 只是估计**：用 Slack 公式（γ 取泊松比估计值）得到 0.41–0.58 W/m·K，**低于 Cahill 最小热导，物理上不合理**，只保留在 CSV 里作参考，不用于结论。要讨论 κ_L，必须做声子非谐性计算。

## 3 电子侧参数（`电子参数_300K.csv`）

每种材料、每种载流子、10¹⁹ 和 10²⁰ 两个浓度各一行，包括：面内 S、m\*_D、m\*_S、面内 m\*_c、AMSET 面内迁移率、加权迁移率 μ_w = μ·(m\*_D)^{3/2}、BoltzTraP2 的 Lorenz 数、AMSET 面内 PF，以及审计分级。

μ、μ_w 和 PF 只从密网格 AMSET（`14_散射机制分项迁移率/密网格AMSET/`）读取。

| 300 K，面内 | PbSb | PbBi | SnSb | SnBi |
|---|---:|---:|---:|---:|
| p 1e19：μ / μ_w / PF（mW/m·K²） | 1118 / 1407 / 11.4 | 1357 / 1129 / 16.1 | 1816 / 1394 / 22.0 | 1530 / 1224 / 17.9 |
| p 1e20：μ / μ_w / PF | 881 / 1261 / 18.5 | 940 / 1005 / 17.7 | 1385 / 1305 / 26.0 | 1093 / 1102 / 20.6 |
| n 1e19：μ / μ_w / PF | 1029 / 272 / 3.6 | 997 / 281 / 5.2 | 667 / 496 / 5.4 | 466 / 547 / 5.2 |
| n 1e20：μ / μ_w / PF | 692 / 281 / 7.6 | 679 / 258 / 7.5 | 446 / 355 / 6.8 | 479 / 478 / 8.6 |

- **p 型**：同浓度下 S 相同，所以 PF 跟着 μ 走，SnSb 最高。但加权迁移率 μ_w = μ·(m\*_D)^{3/2} 在 PbSb 和 SnSb 之间几乎相同（1e20 时 1261 对 1305），Bi 系低约 15–20%：Sn 系迁移率高，Pb 系态密度质量大，两者抵消。所以各自在最优浓度下，p 型 PF 的上限相近；Sn 系的优势只在同一浓度下比较时成立。
- **n 型**：Sn 系 μ_w 更高（态密度质量大，抵消并超过了迁移率的降低），1e19 时 PF 也更高。
- 绝对迁移率可能偏高 5–25%（14_ 第 3 节），μ_w 和 PF 同样。旧的 12×12×2 结果低估 3–4 倍，已作废。S、m\*、Lorenz 来自 28×28 密网格 BoltzTraP2。

### 3.1 双极热导分解（`双极热导分解.csv`）

用 [`10_脚本/bt2_local.py`](../10_脚本/bt2_local.py) 在本地重做 BoltzTraP2（现用带隙、常数弛豫时间、面内）。在同一化学势下，把价带和导带分开积分：
κₑ = κ_p + κ_n + κ_bp，其中 κ_bp = σ_p σ_n /(σ_p + σ_n) ·(S_p − S_n)² T。四个材料上这个等式都严格成立。

| 300 K | 净浓度 | 双极项占 κₑ：PbSb / PbBi / SnSb / SnBi | 实际 L（10⁻⁸ W·Ω/K²） | 扣除双极项后的 L |
|---|---|---|---|---|
| p 型 | 1e19 | 70% / 29% / 25% / 29% | 5.27 / 2.24 / 2.24 / 2.53 | 1.56 / 1.59 / 1.67 / 1.80 |
| n 型 | 1e19 | 70% / 37% / 60% / 75% | 6.71 / 3.35 / 4.11 / 6.08 | 2.04 / 2.11 / 1.65 / 1.52 |
| p 型 | 1e20 | 2% / 0.2% / 0.2% / 0.2% | 1.76 / 1.78 / 1.82 / 1.92 | 1.72 / 1.77 / 1.81 / 1.91 |
| n 型 | 1e20 | 0.8% / 0.1% / 0.5% / 1.0% | 2.58 / 2.41 / 2.55 / 1.97 | 2.56 / 2.41 / 2.53 / 1.96 |

500 K、1e20 时，双极项占比上升到 p 型 8–29%、n 型 8–27%。

- **Lorenz 数偏高完全来自双极热导。** 单载流子部分在 1e19 时为 1.5–2.1，都低于简并值 2.44（非简并和多带效应使它偏低）。
- **n 型比 p 型更容易受双极影响**（1e19 时 37–75% 对 25–29%，PbSb 两者都是 70%）。原因是 n 型的少数载流子是价带空穴，价带态密度大、Seebeck 系数大，(S_p − S_n)² 很大。
- **双极项强烈依赖带隙**：SnBi 的 n 型 1e19，带隙从 0.10 增加到 0.24 eV，L 从 10.4 降到 1.7（12_ 的 `剪刀敏感性_300K.csv`）。所以“孤对电子 s 能级 → 带隙 → κₑ”这条线是否成立、强度多大，取决于带隙本身是否可靠（19_ 计算 1-8）。
- 这里的 L 与集群 BoltzTraP2 的结果相差 10% 以内；n 型 1e19 的差别较大，因为这一点正处在双极项快速变化的区间。
