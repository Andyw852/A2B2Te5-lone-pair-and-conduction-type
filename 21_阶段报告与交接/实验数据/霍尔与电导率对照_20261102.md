# 霍尔数据与电导率：与计算的对照（2026-11-02）

数值由 `python 10_脚本/hall_check.py` 给出；数据见本目录 [`README.md`](README.md)。报告尚未按本文修改。

“HSE”指报告的 HSE 估计（BoltzTraP2 × 多谷模型 HSE/PBE 比值，常数弛豫时间），“PBE”指 PBE+SOC BoltzTraP2 全区。两者与报告图 8、图 9 同口径。

## 结论

1. **σ 的单位是 10⁴ S/m。** 两个测量正常的霍尔样品，σ 表与霍尔 1/ρ 之比都是 1.2（Pb₂Bi₂Te₅ 1.19、Sn₂Bi₂Te₅ 1.20）。
2. **四个霍尔结果中两个可用**：Pb₂Bi₂Te₅、Sn₂Bi₂Te₅。Pb₂Sb₂Te₅、Sn₂Sb₂Te₅ 的浓度、迁移率、霍尔电压、相位被仪器标红；Sn₂Sb₂Te₅ 的 1/ρ 还与 σ 表差 2.35 倍。
3. **Pb₂Bi₂Te₅（n 型）支持 PBE**：在霍尔浓度下 PBE 的 S 与实验相符，HSE 的 |S| 只有实验的约五分之一。
4. **Sn₂Bi₂Te₅（p 型）两种泛函都大致可以**：HSE 反推的浓度是霍尔值的 0.82 倍，PBE 是 1.41 倍。室温下 HSE 更近。
5. **Sn₂Sb₂Te₅ 的霍尔浓度是决定性的数据**，但这次测量不可靠：
   - 若它是对的（1.7×10²¹，比 Sn₂Bi₂Te₅ 高约一倍），PBE 同时解释两个 Sn 样品的 S 及其比值，HSE 不能。Sb 与 Bi 的 S 差别就有一大半来自浓度。
   - 若两个 Sn 样品浓度相近，HSE 的解释（差别来自孤对电子多谷）更好。
   - **需要重测。**
6. **Pb₂Sb₂Te₅**：浓度不可用。但电导率（2200 S/cm）要求载流子至少 10¹⁹–10²⁰ cm⁻³，与报告的近补偿解释（约 10¹⁷ cm⁻³）矛盾。

**Pb₂Bi₂Te₅ 为什么 PBE 对**

- PBE 的导带有三个谷挤在 23 meV 内：Γ–A 驼峰、A（Bi-p 32%）、Γ，态密度大得多。
- 实验要求后者。之前报告说 HSE 与此样品相符，是在浓度可以自由调的前提下。

## 3 两个 Sn 样品：Sb 与 Bi 的 S 差别从哪来

**实验**：300 K 时 S(Sn₂Bi₂Te₅)/S(Sn₂Sb₂Te₅) = 1.85。

**两种浓度假设下的预测**（Sn₂Bi₂Te₅ 都取它的霍尔值 9.1×10²⁰ cm⁻³）：

| Sn₂Sb₂Te₅ 的浓度 | HSE：SnBi / SnSb / 比 | PBE：SnBi / SnSb / 比 |
|---|---|---|
| 与 Sn₂Bi₂Te₅ 相同（9.1×10²⁰） | 25.3 / 11.1 / **2.29** | 38.0 / 29.0 / **1.31** |
| 标红的霍尔值（1.7×10²¹） | 25.3 / 6.0 / **4.21** | 38.0 / 21.6 / **1.76** |

**判读**
- 浓度相近时，比值主要来自能带：HSE 的 2.29 比 PBE 的 1.31 更接近实验。
- 若 Sn₂Sb₂Te₅ 的浓度真是霍尔值，PBE 的 1.76 与实验几乎一致，两个样品的绝对值也都在 +6–9 µV/K 以内；HSE 则差得很远。此时 Sb 与 Bi 的差别大半来自浓度：Sn₂Sb₂Te₅ 的 Sn 空位更多。

**电导率之比不能裁决**
- σ(SnSb)/σ(SnBi) 实验为 1.32。
- 同一弛豫时间下的预测：HSE 浓度 1.11–1.71，PBE 浓度 2.50。
- 这倾向于“浓度相近”，但前提是两个样品的弛豫时间相同。掺杂更重的样品弛豫时间更短很常见，所以这一条不能裁决。

**加权迁移率**（Snyder 2020，约 300 → 620 K，cm²/V·s）：Sn₂Bi₂Te₅ 85 → 43，Sn₂Sb₂Te₅ 61 → 40，Pb₂Bi₂Te₅ 90 → 26。

## 4 Pb₂Sb₂Te₅

- 霍尔浓度不可用（相位 21°）。电阻率可靠：两台仪器相符，2.2×10⁵ S/m。
- 迁移率按 100–1000 cm²/V·s 算，需要 10¹⁹–10²⁰ cm⁻³ 的载流子，而报告的近补偿模型只有约 10¹⁷ cm⁻³。σ 随温度下降也更像简并、类金属的行为。
- 若霍尔值大致可信（1.0×10²¹），HSE 给 S = +8.5（302 K），实验 +5.5，PBE 给 +26；HSE 更近。
- 也可能是电子、空穴都多的补偿。
