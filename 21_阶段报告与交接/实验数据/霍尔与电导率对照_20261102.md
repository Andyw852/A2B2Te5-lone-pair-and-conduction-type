# 霍尔数据与电导率：与计算的对照（2026-11-02）

数值由 `python 10_脚本/hall_check.py` 给出；数据见本目录 [`README.md`](README.md)。报告尚未按本文修改。

## 结论

1. **σ 的单位确定为 10⁴ S/m**：表头如此，两次霍尔测量的电阻率也独立相符（差 10–20%）。
2. **Pb₂Bi₂Te₅（n 型）**：霍尔浓度为 8.1×10¹⁹ cm⁻³。在这个浓度下，PBE+SOC（BoltzTraP2 全区）的 S 与实验相符；HSE 估计的 |S| 只有实验的约五分之一。报告第 5 节“HSE 优于 PBE”的结论，对这个样品不成立。
3. **Pb₂Sb₂Te₅**：霍尔浓度被仪器标红，不可靠。但电导率（2.2×10⁵ S/m，两台仪器相符）说明载流子至少 10¹⁹–10²⁰ cm⁻³。这与报告的近补偿解释（净掺杂约 2×10¹⁶ cm⁻³）矛盾。
4. **两个 Sn 样品**：没有霍尔数据。σ(SnSb)/σ(SnBi) = 1.32（300 K），落在 HSE 的预测（1.1–1.7）之间，远离 PBE 的预测（2.5）。这支持“两个样品浓度相近，Sn₂Bi₂Te₅ 的 S 更高来自能带（孤对电子多谷）”。

（µV/K。HSE 估计 = BoltzTraP2 × 多谷模型 HSE/PBE 比值，与报告图 8 同口径。）

**各方法反推的浓度**
- PBE+SOC BoltzTraP2：8.3×10¹⁹ cm⁻³，与霍尔值只差 3%。
- 报告表 7 的 HSE：8.2×10¹⁸（常数 τ）、3.4×10¹⁸ cm⁻³（声学声子 τ），比霍尔值低 10–24 倍。
- 表 7 的 PBE 列用的是路径多谷模型（3.5×10¹⁹，最大偏差 −104 µV/K）；全区 BoltzTraP2 更可靠，最大偏差只有 −25 µV/K（高温端偏大，即双极效应偏弱）。

**从实验反推有效质量**：单抛物带 Pisarenko 给出 m*_DOS = 0.6–0.8 m_e（常数 τ / 声学声子 τ）。

**原因：导带的谷结构**
- **HSE**：导带是 Γ 处一个很轻的单谷（面内 0.08 m_e），下一个谷 A 高 133 meV。
- **PBE**：Γ–A 线上的驼峰（沿 c 1.23 m_e）、A（+7.9 meV，Bi-p 32%）、Γ（+22.7 meV）三个谷挤在 23 meV 内，态密度大得多。
- **实验**：要求的是态密度大的导带，与 PBE 相符。

**对报告的影响**
- 第 5 节、表 7、图 9(b) 中“Pb₂Bi₂Te₅ 支持 HSE”的说法要改。之前 HSE 能符合，是因为浓度可以自由调；浓度固定为实测值后，就不符了。
- 这也牵动问题一的 n 型结论（“导带底是 Γ 处的孤对电子单谷”）。如果 PBE 的导带更接近实际，Pb₂Bi₂Te₅ 带边附近还有以 Bi-p 为主的 A 谷和 Γ–A 驼峰。
- 只有一个样品、一次室温霍尔，霍尔因子按 1。

## 3 Pb₂Sb₂Te₅

- **霍尔**：p 型 1.04×10²¹ cm⁻³，μ_H = 14.5 cm²/V·s。仪器把浓度、迁移率、霍尔电压（0.61 µV）、相位（21°）标红，浓度不可用。
- **电导率可靠**：两台仪器相符，2.2×10⁵ S/m（2200 S/cm）。迁移率按 100–1000 cm²/V·s 算，需要 10¹⁹–10²⁰ cm⁻³ 的载流子。报告的近补偿模型只有约 10¹⁷ cm⁻³，迁移率要到 10⁴–10⁵ 才能给出这个 σ，不现实。σ 随温度下降（302 → 619 K 降到 0.41 倍）也是简并、类金属的行为。
- **两种可能**：
  - 重掺杂 p 型：若霍尔值大致可信，在 1.0×10²¹ cm⁻³ 下 HSE 估计 S = +8.5（302 K）→ +21（619 K），实验 +5.5 → +17；PBE 为 +26 → +65。
  - 电子、空穴都多的补偿（半金属）。

  两者都需要可靠的霍尔数据才能区分（加大电流或磁场；最好测变磁场霍尔）。
- **对报告的影响**：第 5 节 Pb₂Sb₂Te₅ 的近补偿解释和图 S3 的论证要重写。

## 4 两个 Sn 样品

**σ(SnSb)/σ(SnBi)**
- 实验：1.32（300 K）→ 1.49（620 K）。
- 多谷模型在表 7 的三种反推浓度下的预测（同一弛豫时间，300 K）：

| 能带与散射 | 反推浓度 SnSb / SnBi（cm⁻³） | 预测的 σ 之比 |
|---|---|---|
| HSE，常数 τ | 6.2×10²⁰ / 7.2×10²⁰ | 1.11 |
| HSE，声学声子 τ | 5.4×10²⁰ / 3.5×10²⁰ | 1.71 |
| PBE，常数 τ | 2.3×10²¹ / 1.2×10²¹ | 2.50 |

**解读**：实验值落在 HSE 两种散射之间，远离 PBE。即两个样品的空穴浓度相近，Sn₂Bi₂Te₅ 的 S 更高主要来自能带（孤对电子多谷），而不是浓度。前提是两个样品的散射强度相近；霍尔数据可以直接确认。

**加权迁移率**（Snyder 2020，cm²/V·s，约 300 → 620 K）：
- Sn₂Bi₂Te₅：85 → 43；
- Sn₂Sb₂Te₅：61 → 40；
- Pb₂Bi₂Te₅：90 → 26。

300 K 时 Sn₂Bi₂Te₅ 比 Sn₂Sb₂Te₅ 高约 40%，与它的态密度质量更大（口袋更多）一致。
