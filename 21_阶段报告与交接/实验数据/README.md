| `Pb2Sb2Te5_T_sigma_S.csv` | Pb₂Sb₂Te₅ 的温度、电导率、Seebeck 系数，8 个点（301.6–619.4 K） | 2026-10-29 |

- S 已用于论文报告图 6(a)（`10_脚本/paper_figures.py` 中的 `EXP`）。
- 电导率的单位未给出，暂不用于报告。原因：常数弛豫时间模型只给出 σ/τ，而实测 σ 随温度下降（约 ∝ T⁻¹·²⁴），近补偿模型的 σ/τ 却因本征激发而上升（HSE 约 4.7 倍、PBE 约 38 倍，302 → 619 K），两者对不上。需要霍尔载流子浓度和散射计算后再比较。
- 其余三种材料的实验 S(T) 只有曲线图，报告中用的是读图值。
