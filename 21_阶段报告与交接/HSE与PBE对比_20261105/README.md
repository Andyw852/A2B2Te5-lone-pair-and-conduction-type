## 一句话

- **p 型、低浓度**（谷结构、A 位与 B 位的作用）：HSE 明显得多。PBE 下四种材料的孤对电子谷都在价带顶附近，S 几乎相同，看不出孤对电子的作用，A 位甚至反号；HSE 下只有 Sn₂Bi₂Te₅ 的价带顶是孤对电子多谷，S 随之分开。但现有样品都在约 10²¹ cm⁻³，这部分还没有实验检验。
- **成键（COHP）**：两种泛函相同，HSE 并不更明显。
- **与样品**：两个 Sn 的 p 型样品 HSE 更接近；n 型 Pb₂Bi₂Te₅ 只有 PBE 对（HSE 的导带只剩 Γ 单谷），n 型“导带多谷”的结论靠 PBE 与实验，不靠 HSE。
