# 交接：穿过真实价带极大的附加能带路径（c7_true_path，HSE06+SOC）

## 为什么要算

能带图（图 2、3、5）只画高对称路径。Sn₂Bi₂Te₅ 的真实价带顶 Σ′ 不在路径上，比路径上的最高点高 37.6 meV；孤对电子谷 R₂′ 也比路径上的 R₂ 高 53–62 meV（图 S1）。目前图 3(d) 只用一条红色虚线标出真实价带顶。

这一步补算一段穿过这些极大的路径 **Γ → Σ′ → R₂′ → L**，让能带线本身经过真实价带顶。这段路径全部在含 c 轴的镜面内，折点 Σ′、R₂′ 取自 c5 拟合的真实极大。

## 哪些材料要做

| 材料 | 是否要做 | 原因 |
|---|---|---|
| Sn₂Bi₂Te₅ | **必须** | 价带顶本身在路径外，现有能带图的价带顶和带隙都不是真实值 |
| Sn₂Sb₂Te₅ | **建议** | 价带顶在 Γ，带边没问题；但孤对电子谷比路径上高 4–62 meV（R₂′ 在 −84 meV，路径上是 −146 meV）。补上后，两种 Sn 材料能在同一种图上对比 |
| Pb₂Sb₂Te₅、Pb₂Bi₂Te₅ | 不做 | 价带顶在 Γ–A 轴上（Γ、A），就在路径上，带边是真实的。Pb 系也没做过镜面搜索，不知道真实谷在哪里，没法设计这段路径 |

## 推送与分析

每批推送 `PROCAR_OPT.gz`、`OSZICAR`、`out.log` 尾部，再运行：

```bash
python 10_脚本/true_valley_path.py check 22_能带基准_1-0/Sn2Bi2Te5/c7_true_path \
  --parts 22_能带基准_1-0/Sn2Bi2Te5/c7_true_path/b01 22_能带基准_1-0/Sn2Bi2Te5/c7_true_path/b02 \
  | tee 22_能带基准_1-0/Sn2Bi2Te5/c7_true_path/check.log
python 10_脚本/true_valley_path.py check 22_能带基准_1-0/Sn2Sb2Te5/c7_true_path \
  --parts 22_能带基准_1-0/Sn2Sb2Te5/c7_true_path/b01 22_能带基准_1-0/Sn2Sb2Te5/c7_true_path/b02 \
  | tee 22_能带基准_1-0/Sn2Sb2Te5/c7_true_path/check.log
```

把 `check.log` 和 `true_path_eigen.csv` 一起推送。

**验收**：
- 锚点与 c2 路径的差 < 0.5 meV；
- 折点处的能量与 c5 极值相差 < 2 meV。Σ′、R₂′ 都要看，c5 是拟合值，差一点正常；
- “本路径上价带最高”与真实价带顶相差 < 2 meV。SnSb 的价带顶在 Γ，本路径的起点就是 Γ。

任一不满足就停下汇报。
