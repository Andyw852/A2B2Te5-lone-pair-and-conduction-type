# Pb₂Sb₂Te₅ · c2_hse（HSE06+SOC 能带路径）

2026-10-27 完成。**这是四种材料 HSE 路径的最后一个（4/4）。**

## 1. 计算设置

| 项 | 值 |
|---|---|
| 体系 | Pb₂Sb₂Te₅，9 原子，P-3m1 |
| 泛函 | HSE06（`LHFCALC=.TRUE.`） |
| SOC | 是（`LSORBIT=.TRUE.`，`vasp_ncl`） |
| **NELECT** | **68**（VBM = 第 68 带，CBM = 第 69 带；Sb 体系不含 5d 半芯） |
| ENCUT | 360 eV |
| k 网格（SCF） | 12×12×2 |
| **路径** | `KPOINTS_OPT`，**204 个点**（与另三种材料同一条路径） |
| 起点 | PBE SCF 的 WAVECAR（`ISTART=1`，`TIME=0.2`） |
| 作业 | hanhai `308185`，64 核，耗时 **17:43** |

## 2. 带边结果

| 量 | 值 |
|---|---|
| VBM | **6.2367 eV @ Γ**（k=0） |
| CBM | **6.2879 eV @ Γ**（k=0） |
| **路径带隙** | **0.0512 eV**（**Γ 点直接**） |
| `E-fermi` | 6.2621 eV |

**PbSb 是四种材料里唯一 Γ 直接带隙的**，且带隙极小（51 meV）。

## 3. 与 SCF 网格（`c1_HSE_SOC`，12×12×2）的交叉验证

| 量 | `c1_HSE_SOC` | `c2_hse` 路径 | 差 |
|---|---:|---:|---:|
| VBM | 6.236954 | 6.236700 | **−0.25 meV** |
| CBM | 6.288293 | 6.287900 | **−0.39 meV** |
| 带隙 | 0.051339 | **0.051200** | −0.14 meV |
| Γ 点全部 128 带最大差 | — | — | **1.7 meV** |

**验证通过（亚 meV）**。注意：本材料的差异（0.25–0.39 meV）比另三种（～10⁻⁵ eV）大约 10–40 倍，
原因是本体系的 HSE SCF 从 **PBE** WAVECAR 起步（另三种从其 HSE WAVECAR 起步），
波函数起点不同带来约 0.4 meV 的差异。**对带边位置与带隙影响可忽略（<0.5 meV）。**

## 4. 四种材料 HSE 路径汇总

| 材料 | VBM 位置 | CBM 位置 | 路径带隙 | 类型 |

## 5. 文件说明

| 文件 | 内容 |
|---|---|
| `path_eigen.txt` | 204 个 k 点 × 128 条带，三列 `k_index band_index energy_eV` |
| `KPOINTS_OPT` | 204 点路径定义 |
| `INCAR` / `KPOINTS` | SCF 设置 |
| `PROCAR_OPT.gz` | 路径投影（fat-band / 成分分析用） |

## 6. 提取方法

```
python ext_opt2.py vasprun.xml 204 path_eigen.txt
```

本征值在 `vasprun.xml` 的 `<eigenvalues_kpoints_opt>` 段，**不在** `EIGENVAL` 里。
