2026-10-24 完成 Pb₂Sb₂Te₅；2026-10-26 补齐 Pb₂Bi₂Te₅、Sn₂Sb₂Te₅、Sn₂Bi₂Te₅（见“四种材料对比”）。这是问题一（孤对电子与电输运）的**能带基准**：此前所有依赖带隙的结论

## 三条结论

### 1. HSE 把 PbSb 的带隙压到 51 meV，只有 PBE 的 1/4.4

```
PBE+SOC  0.2268 eV
HSE+SOC  0.0513 eV     比值 0.226
```

### 2. PBE 给间接带隙，HSE 给 Γ 点直接带隙

PBE 的 VBM 在 k#3、CBM 在 k#1；HSE 的 VBM 与 CBM 都在 Γ（k#1）。
HSE 下 Γ 点带隙比 PBE 小，与 12_ 中“PBE+SOC 在 Γ 点可能能带反转”的猜测相容，但**不能据此判断反转与否**：51 meV 的带隙在反转的哪一侧，要看 TRIM 点宇称（待补第 2 项）。

### 3. 旧 HSE 的 0.065 eV 数值上接近，但计算本身是错的

旧 HSE 用 `ISYM=0` 配不可约 k 点列表，电荷密度与交换算符未按对称性补全。
新 HSE（`ISYM=3`、与 PBE 同一 38 点网格）给出 **0.0513 eV**。
数值相近纯属巧合，**不能再用旧值做依据**。

**结论：在 HSE 下，PbSb 的价带从多谷变成 Γ 单谷。**

- PBE：价带顶在 Γ–M 线上 (1/6, 0, 0) 的 6 个等价点，Γ 只低 5.8 meV，A 低 22.8 meV，25 meV 内共 8 个 k 点。这就是 12_、15_ 中 PbSb 价带“有效谷数约 12”的来源。
- HSE：只剩 Γ。A 和 (1/6, 0, 0) 分别低 196 和 236 meV，是 300 K 时 kT（26 meV）的 8–9 倍，对输运几乎没有贡献。
- 导带两者都是 Γ 单谷；HSE 下最近的 A 谷从 +109 升到 +294 meV。
- PBE 的价带沿 Γ–M 不单调：Γ 高、(1/12, 0, 0) 低 159 meV、(1/6, 0, 0) 又回到最高。Γ 处的价带态和 (1/6, 0, 0) 的价带谷可能来自不同的轨道成分，HSE 把后者压下去了。这与“PBE+SOC 在 Γ 点能带反转、HSE 削弱反转”相容，但要用 TRIM 点宇称确认（待补第 2 项），并看 Γ 处第 68/69 条带的阳离子 s 成分（c1 设了 `LORBIT = 11`）。
- 网格只有 12×12×2，谷的精确位置和深度需要能带路径（c2）确认；但 200 meV 以上的差距不会因加密网格而消失。

**对问题一的影响（PbSb）**：

- p 型同浓度 S、m\*_S、态密度质量、价带谷数，以及 λ 扫描中“回中后谷数 12 → 6”，都依赖 PBE 的多谷价带，在 HSE 下不成立。Γ 单谷、窄带隙意味着态密度质量小，同浓度 p 型 S 预计明显低于 PBE 结果，“p 型四种材料 S 相同”对 PbSb 要用 HSE 能带重新检验。
- 迁移率（电导质量）和双极项同样要重算。
- n 型受影响较小（两者导带都是 Γ 单谷），但窄带隙会使 Γ 导带更轻，也要复核。
- 剪刀修正不能补救，因为它不改变谷结构。要得到可信的 PbSb 输运，需要 HSE 级别的能带（例如 HSE 自洽后用 Wannier 插值，再算 BoltzTraP2）。

**先要回答的问题**：其余三种材料是否也这样。若 Bi 系、Sn 系在 HSE 下同样变成 Γ 单谷，问题一中依赖能带形状的结论需要整体改用 HSE 能带；若只有 PbSb 如此，只需单独处理 PbSb。所以 Bi 系、SnSb 的 HSE（同一 12×12×2 网格、同一设置）优先级应提到最高。

→ **已回答（2026-10-26）**：价带多谷只在 SnBi 保留，四种材料都要用 HSE 能带重做，见下节。

## 四种材料对比（2026-10-26 补齐 PbBi、SnSb、SnBi）

设置与 PbSb 相同：同一 Γ 12×12×2 网格（38 个不可约点），PBE 为 1-0 的 a_pbe，HSE 为 c_hse_A（`ALGO=Damped`、`TIME=0.2`、`NELM=250`、`ISYM=3`、`PRECFOCK=Fast`、`NKREDX/Y=2`）。三种材料的 HSE 都出现 `aborting loop because EDIFF is reached`；PbBi、SnSb 另用 `ALGO=All` 交叉核对，总能分别差 2.2、3.7 μeV。数据在 `<材料>/b_PBE_SOC/`、`<材料>/c1_HSE_SOC/`（子目录名沿用 PbSb，便于脚本复用），逐点对比在 `<材料>/逐k点对比.txt`，HSE 带边成分在 `<材料>/带边成分_HSE.txt`（脚本 `10_脚本/band_edge_composition.py`）。

**自查**：PBE+SOC 与 08_（Γ 9×9×2）在两套网格共有的 6 个 k 点（Γ、A、(1/3,0,0)、(1/3,0,1/2)、K、H）上，直接带隙和相对 Γ 的价带能量相差不超过 1.5 meV，四种材料都是，说明结构、POTCAR、能带序号一致。最小带隙不同（SnSb 0.216 对 0.251、SnBi 0.130 对 0.163 eV）只因 9×9×2 网格不含价带顶所在的 (1/6,0,0)；20_ 里这两个值是上限。

## 宇称与 Z2（2026-10-27）

方法：irrep 3.2.0（`-kpoints=1,7,20,26`，带范围覆盖全部占据带）与 `10_脚本/trim_parity.py`（直接读 WAVECAR，简并子空间内 O⁻¹P 的本征值）两法交叉核对；反演中心在原点（中心 Te）。k 点 1、7、20、26 = Γ、M、A、L。δ 为该点全部占据带（含半芯，每个 Kramers 对计一次）的宇称乘积。强 Z2：(−1)^ν₀ = δ_Γ·δ_A·δ_M³·δ_L³（M、L 各 3 个等价点）；弱指标由对应平面上的 TRIM 点算，均为 0。

| 材料 | 泛函 | δ_Γ | δ_M | δ_A | δ_L | Z2 |
|---|---|---:|---:|---:|---:|---|
| SnSb | PBE+SOC | −1 | +1 | +1 | +1 | (1;000) |
| SnSb | HSE+SOC | −1 | +1 | +1 | +1 | (1;000) |
| PbBi | PBE+SOC | +1 | −1 | −1 | −1 | (1;000) |
| PbBi | HSE+SOC | +1 | −1 | −1 | −1 | (1;000) |
| SnBi | PBE+SOC | +1 | −1 | −1 | −1 | (1;000) |
| SnBi | HSE+SOC | +1 | −1 | −1 | −1 | (1;000) |
| PbSb | — | 待 c1 的 WAVECAR | | | | |

irrep（SnSb，HSE）：Z2 = 1、Z4 = 3。它打印的“inversion-odd Kramers pairs : 71”是 8 个 TRIM 点（含等价点）上奇宇称占据 Kramers 对的总数：71 mod 2 = 1、71 mod 4 = 3，正好就是 Z2 和 Z4。

**读法**：

- 三种材料在 PBE 和 HSE 下都是强拓扑绝缘体 (1;000)，两种泛函的拓扑相同。
- **反转都在 Γ。** 每一行里，Γ 都是唯一与其余 TRIM 点（M、A、L）不同号的点。Bi 系整行翻号来自 Bi 5d 半芯：两个 Bi 关于反演中心成对，其满 d 壳层在每个 TRIM 点上都贡献 (−1)^5 = −1，8 个点一起翻号，不改变 Z2，也不改变“Γ 与其余不同”（Pb、Sn 的 d 半芯在四种材料里都有，Sb 的 POTCAR 没有 d 半芯）。**已验证**（2026-10-27）：`trim_parity.py --first 21` 去掉 Bi 5d 的第 1–20 条带后，PbBi、SnBi 的 δ 都变为 {Γ −1，M/A/L +1}，与 SnSb 相同。
- 结合成分：三种材料 Γ 处的导带底都是阳离子 s–Te p 反键态（孤对电子态），价带顶是阳离子 p。**孤对电子的 s 态在 Γ 处被反转到 p 态之上，这正是非平庸拓扑的来源**，PBE 和 HSE 都如此，HSE 只是把 Γ 处的反转带隙减小（SnSb 252 → 168、PbBi 365 → 194、SnBi 360 → 277 meV）。PbSb 的成分（c1）也是同样带序，宇称待补。

## 对已有结论的影响（PbSb，2026-10-24）

| 结论 | 原依据带隙 | 新 HSE 带隙 | 影响 |
|---|---:|---:|---|
| 低浓度 S 由带隙决定、p 型 S 峰值 | 0.065 | **0.0513** | 双极效应更强，S 峰值更低 |
| n 型 S 变号阈值（原 3.0e18） | 0.065 | 0.0513 | 阈值会**更小** |
| 双极热导分解（Lorenz 5.3 → 1.6） | 0.065 | 0.0513 | 双极贡献会**更大** |
| 剪刀修正本身 | — | — | **见下：不能只把剪刀目标改成 0.0513** |

**不能只把剪刀目标从 0.065 改成 0.0513。** 剪刀是把 PBE 导带整体平移，只在 HSE 与 PBE 的能带形状相同时成立。这里 HSE 把价带顶从 k#3 移到了 Γ，带边位置变了，PBE+剪刀给出的价带谷结构（12_、15_ 中 PbSb 价带有效谷数约 12）和 HSE 不一致。所以：

- 依赖能带形状的结论（同浓度 S、m\*_S、电导质量、迁移率、λ 扫描的谷数变化）对 PbSb **不只是绝对值要复核，而是要先看 HSE 下价带的多谷结构是否还在**；
- 低浓度、双极相关的结论方向不变（带隙更小，双极更强），数值要重算；
- 其余三种材料的新 HSE 还没算，“PbSb 带隙最小”目前没有依据（旧 HSE 的排序不能用）。
