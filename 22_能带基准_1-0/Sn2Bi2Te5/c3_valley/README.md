# Sn₂Bi₂Te₅ · c3_valley：价带孤对电子谷的完整有效质量张量（HSE06+SOC）

2026-10-28，用户同意补算。目的：c2 路径只给出沿路径一个方向的质量；SnBi 的价带顶是三组离轴的孤对电子谷（17 meV 内，各六重），多谷模型估同浓度 S 需要它们的完整质量张量。

## 设置

**与 `../c2_hse/` 完全相同**（同一 INCAR、同一 Γ 12×12×2 自洽、从 c_hse_A 的 HSE WAVECAR 起步，`ISTART = 1`，`LORBIT = 11`），只把 `KPOINTS_OPT` 换成本目录的 37 个点（一批即可）。

| 内容 | 序号（0 起） |
|---|---|
| 谷 #11（Γ–M 上，中心 (−0.16543, 0, 0)）的 11 点星形 | 0–10 |
| 谷 #101（A–L 上，中心 (−0.05690, 0, −1/2)） | 11–21 |
| 谷 #119（A–L 上，中心 (−0.33469, 0, −1/2)） | 22–32 |
| 校验点：c2 路径的 #0（Γ）、#11、#101、#119 | 33–36 |

谷心由 c2 HSE 路径上 5 点抛物线拟合定出。每个谷 11 点：中心；沿线 ±δ；面内垂直 ±δ；沿 c ±δz；（线, c）平面对角 (±δ, ±δz)，δ = 0.02、δz = 0.03 Å⁻¹。对称依据：含该线与 c 轴的镜面是对称操作（已用 SnBi 结构核对；沿线的二重轴、水平镜面不是），所以面内垂直方向是主轴，线与 c 方向可以耦合。点的几何与顺序见 `c3_points.json`。

## 要推送的输出

`PROCAR_OPT.gz`（**必须**：拟合用它的 8 位小数能量；vasprun.xml 里的本征值只有 4 位小数，即 0.1 meV，对沿 c 的重质量不够）、`c3_eigen.txt`（`ext_opt2.py vasprun.xml 37 c3_eigen.txt`，作对照）、`INCAR`、`KPOINTS`。

## 拟合

`python 10_脚本/c3_valley_mass.py fit 22_能带基准_1-0/Sn2Bi2Te5/c3_valley`：给出每个谷的梯度（应≈0，面内垂直方向由镜面严格为 0）、曲率、主质量和态密度质量，并判断是否真极值（三个主曲率同号）。验收：校验点与 c2 路径一致到 0.1 meV。脚本已用合成数据（已知含交叉项的质量张量）测过，能精确还原。
