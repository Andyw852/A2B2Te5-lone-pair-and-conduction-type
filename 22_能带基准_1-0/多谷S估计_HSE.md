## 1 方法

- **能谷直接取自 c2 路径**（窗口 300 meV）：Γ、A、L、M 等对称点的谷，三个主方向都用路径上的真实色散；线段内部的离轴谷，沿线用真实色散，面内垂直取沿线的质量，沿 c 用余弦估计（同一面内位置 kz = 0 与 1/2 的能量差）。鞍点舍去。每个方向的色散用 Kane 两带式 ε(1 + ε/E_K) = ħ²k²/2m 拟合（路径步长约 0.025 Å⁻¹，轻带在 0.25 eV 内只有 2–3 个点）。沿 c 碰到布里渊区边界时按截断椭球计算。
- **输运**：常数弛豫时间（CRTA，与 2.4 节旧的 BoltzTraP2 口径相同），面内，300 K，含双极；另用声学形变势（τ ∝ 1/g）做对照。
- **校准**：同一模型跑 PBE 路径，与 2.4 节 PBE + BoltzTraP2 的数值比较。模型多数偏高 1.2–1.8 倍（p 型 3e19 时 1.18–1.39；PbBi 的 n 型 3e19 例外，为 0.73），原因包括椭球近似和环状极值（如 PbSb 的 PBE 价带在 A 附近成环，被当成两组谷）。所以**最佳估计 = BoltzTraP2 的 PBE 值 × 模型的 HSE/PBE 比值**，系统误差大部分抵消。余弦估计的沿 c 质量全部加倍，修正后的估计只变 0–8%（多数 ≤ 5%）。

## 3 读法

- **p 型：HSE 下同浓度 S 的排序 SnBi > SnSb > PbBi > PbSb**，PBE 下四者相同的结论不再成立。决定因素是孤对电子谷离价带顶多近、以及占了多少电导：SnBi 的价带顶就是孤对电子多谷，S 保持甚至略升；SnSb 的 Γ 带很轻，3e19 时费米能级深入 127 meV，碰到 −131 meV 处的孤对电子谷，它们贡献约一半电导，S 降得不多；PbBi 的孤对电子谷只占 12%；PbSb 的 Γ 带近乎线性（带隙 51 meV），孤对电子谷在 236 meV 以下，S 降到 PBE 的 30–40%。
- **n 型：Sn 系 |S| 比 Pb 系高 2.4–3.7 倍**（3e19），PBE 下只高 25–45%。Pb 系的导带是单个很轻的 Kane 型 Γ 谷（孤对电子 s 态），没有别的谷可借；Sn 系的 Γ 导带较重，另有 65–70 meV 处的 A–L 阳离子 p 口袋，3e19 时它承担一半以上的电导。所以 n 型载流子在带边处是孤对电子 s 态，但 Sn 系同浓度 |S| 高的主要原因是 A–L 的阳离子 p 口袋，不是孤对电子。
- **局限**：椭球近似、单带序号、散射简化；绝对值靠 BoltzTraP2 的 PBE 值校准，只宜看排序和 PBE → HSE 的变化方向。PbSb、PbBi 这类近线性的轻带，S 对散射机制很敏感（POP 主导时会比 CRTA 更高）。
