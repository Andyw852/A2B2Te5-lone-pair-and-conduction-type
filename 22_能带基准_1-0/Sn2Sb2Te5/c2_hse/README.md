# Sn₂Sb₂Te₅ · c2_hse（HSE06+SOC 能带路径）

2026-10-27 完成。这是问题一「用 HSE 能带重做输运分析」所需的路径数据。

## 1. 计算设置

| 项 | 值 |
|---|---|
| 体系 | Sn₂Sb₂Te₅，9 原子，P-3m1 |
| 泛函 | HSE06（`LHFCALC=.TRUE.`） |
| SOC | 是（`LSORBIT=.TRUE.`，`vasp_ncl`） |
| NELECT | 68（VBM = 第 68 带，CBM = 第 69 带） |
| ENCUT | 360 eV |
| k 网格（SCF） | 12×12×2，38 个不可约点 |
| **路径** | `KPOINTS_OPT`，**204 个点**，分 6 批（38/38/38/38/38/14） |
| 起点 | `c_hse_A` 的 HSE WAVECAR（`ISTART=1`） |
| 作业 | hanhai `307637`，64 核，耗时 **13:03**（3 天墙钟内） |

## 2. 带边结果

| 量 | 值 |
|---|---|
| **VBM** | 6.6893 eV @ k=0（近 Γ） |
| **CBM** | 6.8496 eV @ k=92（Γ–A 上，kz≈−0.21） |
| **路径带隙** | **0.1603 eV** |
| `E-fermi` | 6.7735 eV |

## 3. 与 SCF 网格（`c_hse_A`）的交叉验证

| 量 | `c_hse_A`（12×12×2，38 点） | `c2_hse`（204 点路径） | 差 |
|---|---:|---:|---:|
| Γ 点 E68 | 6.689321 | 6.689300 | **−2.1×10⁻⁵ eV** |
| Γ 点 E69 | 6.857661 | 6.857600 | **−6.1×10⁻⁵ eV** |
| VBM | 6.689321 | 6.689300 | −2.1×10⁻⁵ |
| CBM | 6.857661 | **6.849600** | **−8.1×10⁻³** |
| 带隙 | 0.168340 | **0.160300** | **−8.0×10⁻³** |

**Γ 点逐带对比**：前 20 带差 ≤ 1.2×10⁻⁴ eV，第 60–75 带差 ≤ 6×10⁻⁵ eV。
**两条独立计算在 Γ 点吻合到 10⁻⁵ eV 量级，验证通过。**

**CBM 低 8.1 meV 是预期的**：12×12×2 网格在 kz 方向只有 0 和 1/2 两个值，
看不到 Γ–A 上 kz≈−0.21 处的 CBM 极小；204 点路径能看到。
这与 PBE 的情况完全一致（见下）。

## 4. 与 PBE 路径的对比

| 泛函 | VBM | CBM | **路径带隙** |
|---|---:|---:|---:|
| PBE+SOC | 6.7638 @ k=10 | 6.9341 @ k=94 | **0.1703 eV** |
| **HSE+SOC** | 6.6893 @ k=0 | 6.8496 @ k=92 | **0.1603 eV** |
| **差（HSE−PBE）** | — | — | **−0.0100 eV** |

**HSE 使路径带隙缩小 10 meV**，与网格带隙的趋势一致：

| | PBE | HSE | HSE−PBE |
|---|---:|---:|---:|
| 网格（12×12×2） | 0.2164 | 0.1683 | **−0.0481** |
| **路径（204 点）** | 0.1703 | **0.1603** | **−0.0100** |

**关键点**：网格带隙在 HSE 下缩小 48 meV，但**路径带隙只缩小 10 meV**——
因为 HSE 不仅缩小 Γ 处的反转带隙，也移动了 Γ–A 上的 CBM 极小位置。
**因此用 HSE 重做输运时，路径带隙（0.1603）而非网格带隙（0.1683）才是正确的输入。**

## 5. 文件说明

| 文件 | 内容 |
|---|---|
| `path_eigen.txt` | 204 个 k 点 × 128 条带的本征值，三列 `k_index band_index energy_eV` |
| `KPOINTS_OPT` | 204 点路径定义（6 段：Γ–M–K–Γ–A–L–H–A） |
| `INCAR` / `KPOINTS` | SCF 设置 |

## 6. 提取方法

```
python ext_opt2.py vasprun.xml 204 path_eigen.txt
```

**注意**：`KPOINTS_OPT` 的本征值在 `vasprun.xml` 的 `<eigenvalues_kpoints_opt>` 段，
**不在** `EIGENVAL` 里（`EIGENVAL` 只含 SCF 的 38 个 k 点）。
`vasprun.xml` 有 106 MB，提取后 `path_eigen.txt` 只有 429 KB。
