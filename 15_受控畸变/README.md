# 受控畸变：把孤对电子的结构表现单独拿出来

2026-10-18。本目录只包含结构和计算方案，**没有运行 DFT**。结构由 [`10_脚本/controlled_distortion.py`](../10_脚本/controlled_distortion.py) 从各材料已弛豫的 9 原子 PBE-D3 结构生成。

## 1 先看现有结构里“畸变在哪里”

P-3m1 结构中，A 位和 B 位的阳离子都只能沿 c 轴偏离各自 TeTe₆ 八面体的中心，偏离后就形成 3 短 + 3 长的配位（`键长与偏心.csv`）：

| 材料 | B 位偏心 / Å | B–Te 短 / 长（Å） | A 位偏心 / Å | A–Te 短 / 长（Å） |
|---|---:|---|---:|---|
| Pb₂Sb₂Te₅ | 0.137 | 3.017 / 3.174 | 0.007 | 3.202 / 3.211 |
| Pb₂Bi₂Te₅ | 0.155 | 3.075 / 3.255 | 0.007 | 3.210 / 3.219 |
| Sn₂Sb₂Te₅ | 0.139 | 3.013 / 3.176 | 0.018 | 3.122 / 3.143 |
| Sn₂Bi₂Te₅ | 0.159 | 3.070 / 3.257 | 0.015 | 3.133 / 3.150 |

- **B 位（Sb/Bi）有明显偏心**，短键朝向范德华间隙一侧的 Te。这种偏心有两种来源：一是孤对电子的 s–p 混合（二阶 Jahn–Teller 效应），二是层端效应（间隙一侧的 Te 只连 3 个阳离子）。受控畸变正是用来把两者分开的。
- **A 位（Pb/Sn）几乎居中。** A 位的 ns² 孤对电子只体现在电子结构上（VBM 处的 A-s/Te-p 反键），不体现在几何上。所以对 A 位，“去掉畸变”这个开关不起作用，要用第 5 节的电子开关。

## 2 结构（每个材料一个子目录）

- λ 表示偏心程度：z(λ) = z_中心 + λ·(z_弛豫 − z_中心)。中心取 6 个最近邻 Te 的平均 z。晶格常数和所有 Te 坐标都冻结在弛豫值，只移动阳离子。
- `POSCAR_lam1.00`：与已弛豫结构完全相同（已逐坐标核对）。
- `POSCAR_lam0.00`：A 和 B 都移到八面体中心，6 根键等长。`POSCAR_lam0.50` 为偏心减半；`POSCAR_lam1.25` 为偏心增强 25%，用来检验响应是否线性。
- `*_Bonly`：只移动 B 位，A 位保持弛豫位置。A 位本来几乎不偏心，这一组用来确认结果确实来自 B 位。

另外建议补一个“约束弛豫”的对照（不在本目录）：B 原子用选择性动力学固定 z，让 Te 自由弛豫；弛豫后把 B 重新放回中心，重复 2–3 轮。这样可以检查冻结 Te 带来的误差。

## 3 每个 λ 要算什么（9 原子胞，成本低）

| 步 | 计算 | 得到 | 与现有流程的关系 |
|---|---|---|---|
| 1 | SOC 自洽（与 step3 相同的 INCAR） | 总能 E(λ)：畸变稳定能 E(0) − E(1) | 新算 |
| 2 | 密网格 SOC 非自洽（28×28×6/7，`ISYM=-1`，`LORBIT=11`，`LWAVE=.TRUE.`） | 带隙、能谷、m\*_D、m\*_c、m\*_S、带边 s 占比（DOS 加权与电导加权） | 再跑 BoltzTraP2 和 `seebeck_mass.py`。剪刀量固定为 λ=1 时的值，不按目标带隙重新调，否则带隙的变化会被抹掉 |
| 3 | COHP（COGITO，无 SOC 即可） | B-s/Te-p、A-s/Te-p 在 E_F 以下的反键积分，ICOHP | 与 `06_COGITO` 同参数 |
| 4 | `LEPSILON` 只取电子部分 | ε∞ 和玻恩有效电荷 Z\* | λ≠1 时结构不在能量极小点，离子部分 ε₀ 和 ω_LO 没有意义，统一沿用 λ=1 的值 |
| 5 | AMSET 形变势（不弛豫的应变胞） | 带边 E1 | 按 AMSET 的 deform 流程 |
| 6 | AMSET（ADP+POP+IMP） | 分项迁移率 | 能带、波函数、形变势和 ε∞ 用该 λ 的值；ε₀、ω_LO、Cᵢⱼ 沿用 λ=1 |

最低限度的方案：只对比 λ = 0 和 1。λ = 0.5 用来看变化趋势。四个材料各做三个 λ，再算 Pb₂Sb₂Te₅ 和 Pb₂Bi₂Te₅ 的 `Bonly`。

## 4 怎么读结果

- 把 λ: 1→0 时各量的变化排成一张表：E、带隙、N_v、m\*_D、m\*_c、同浓度下的 S、σ/τ、ε∞、Z\*、E1，以及分项迁移率。
- **判断孤对电子是否参与**：去掉畸变后，B-s/Te-p 的反键填充应该增加（因为畸变的作用正是缓解这部分反键）。Sb 与 Bi 也可以互相对照：Bi 6s 受相对论收缩，更惰性，Δ 的大小应该随之不同。如果反键填充几乎不变，偏心主要来自层端效应，就不应把它归给孤对电子。
- **判断它是否影响输运**：只有在同一载流子浓度下 S 或 μ 的变化明显超过数值误差，才能说“B 位孤对电子的立体化学活性调控了这一输运参数”。如果变化很小，也是一个结论：输运不受这一畸变控制。

## 5 A 位（Pb/Sn）的电子开关

A 位不偏心，需要在**固定几何**下改变 A-s 能级。
- **VASP 虚晶近似（`VCA` 标签）**：A 位取 Pb₁₋ₓSnₓ（x = 0、0.5、1），POTCAR 同时包含 Pb_d 和 Sn_d。结构固定为母体弛豫结构，再重复第 3 节的步骤 2–3。Pb 6s 因相对论收缩比 Sn 5s 更深，改变 x 就是连续调节 A-s 与 Te-p 的能量差。
- **静水压或应变扫描**作为补充：例如 0、±2 GPa，或体积变化 ±3%，每个点都完整弛豫。
